配对一台手机

  1. 手机连上跟这台电脑同一个 WiFi
  2. 用手机相机或微信扫左边的二维码
  3. 打开后点浏览器的「添加到主屏幕」，以后就像 App 一样点开

二维码只能用一次，扫完自动换新的，可以接着配下一台。

打不开？

  • 第一次打开开关时 Windows 会问要不要允许联网 —— 选允许，「专用网络」和「公用网络」都勾上。Windows 11 常把家里的 WiFi 也标成「公用网络」，只勾专用的话手机照样连不上。
  • 当时点了「取消」、或者只勾了一个：到 Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 更改设置，找到「家庭管家」，两个框都勾上。
  • 电脑睡眠或者关掉了这个软件，手机就连不上。
  • 公司、酒店、商场的 WiFi 常常不让设备之间互相访问，那种网络下用不了；家里的路由器一般没问题。
  • 出了家门、用手机流量是连不上的 —— 只在同一个 WiFi 里有效。
