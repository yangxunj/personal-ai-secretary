# 本机 Codex 对话

2026-10-13 实现；2026-10-14 随 v0.4.0 Windows 桌面版发布。打包验证见 [v0.4.0 发布记录](releases/v0.4.0.md)。

## 使用

1. 在运行平台的电脑安装 Codex 并登录。可复用已有登录，无需复制认证文件或填写 DeepSeek Key。
2. 设置 → 对话后端 → 本机 Codex。路径可留空自动查找，找不到时填完整可执行文件路径（Windows 使用 codex.exe，不接受 .cmd / .bat）。模型留空沿用本机默认；保存会检查登录与模型目录。
3. 如需验证实际模型权限，点「测试本机 Codex」，会消耗少量额度；目录中有模型不等于账号实际可用。
4. 开启新对话。已有对话保留原来的后端，切换默认不会将 API 历史静默导入 Codex。

设置页另有「Codex 公开网络搜索（试用）」，默认关闭。使用本机 Codex 的登录和额度，不需要 DeepSeek 搜索 key；开启或关闭后，已有 Codex 对话的下一轮同样生效，不重建 thread。仅用于公开信息，不登录网页、填表或提交申请。Pi 搜索开关与它独立。

桌面应用自动启用；本地源码 .env 设置 ENABLE_LOCAL_CODEX=true。默认不在公网部署中启用；服务器不能自动使用访客电脑的登录。
本机指平台和 Codex 在本机运行，模型推理仍需联网。使用本机登录对应的订阅额度或 API 配置，不是无限免费额度。手机访问沿用桌面配对入口，电脑需保持运行。

## 能力与边界

- 普通多轮聊天；每个 Conversation 对应独立持久 Codex thread，每轮恢复，不接续桌面正在使用的会话。
- 调用原 buildAgentTools，复用任务、资料、留档、文件、账单/体检导入、财务/健康/保单查询、页面及 pageStore 工具和参数校验。所有后端共用同一份业务库。
- 附件复用现有 intake/extractDoc：图片、文本、PDF、DOCX、XLSX；实际可读程度沿用原格式支持和所选模型视觉能力。
- 网页独立 Codex 调用，沿用需求、真实数据、设计规范、HTML 提取、版本和存储。按实际模型目录选择 max / xhigh / high 等支持的较高推理档位，显示流式制作进度。
- 已接收的请求在关闭/刷新网页后继续；刷新期间显示后台状态，完成后重新加载历史。点击停止会中断本轮；已经完成的业务修改不会回滚。
- 使用客户端消息 id 去重。同一请求重复提交返回原结果；失败/重启中断的请求不自动重放，应先核对已经保存的业务结果。
- 工具运行编号、参数、结果单独留审计；业务工具的数据修改和成功审计在同一 SQLite 事务中完成。网页生成与标记为耗时只读的工具独立保存运行审计，不占用长写事务。Codex 原生搜索记录工具次数与完成/失败状态，不在平台审计里保存完整搜索词或网页正文。
- Codex 对话标题采用首句摘要，不额外调用 API 模型。

支持普通多对话以及任务专属聊天浮层；任务会话、每轮最新上下文与服务端任务范围保护见 [任务专属AI对话.md](任务专属AI对话.md)。任务范围内只提供当前任务的查询/修改、关联待办创建、进展留档和附件归档；其他业务操作在通用对话中完成。语音、额外插件、桌面完整 skills 或邮箱工具不会自动获得。

## 开发与运维

协议实现 src/lib/codex/protocol.mjs；Next 内的接入与工具适配 src/lib/codex/chat.ts。没有另开的后台端口。Next 直接提供现有工具，避免复制工具逻辑和 revalidatePath 的跨进程问题。
每轮启动私有 stdio app-server，完成后关闭，下一轮 thread/resume；子进程监督器在 Next 退出后关闭 Codex，适配 Electron 的 Node 子进程。仅检测安装者的可执行文件，安装包不携带 Codex 登录、会话或本机路径。
shell、plugins、浏览器/电脑操作与继承的 MCP 服务器在此连接禁用；权限/终端/文件修改请求拒绝。Apps 默认全部禁用；仅在聊天搜索开关开启时，替换整张 apps 表并只允许搜索服务的 `web_run`。启动与 thread start/resume 使用一致的搜索策略，临时页面生成、连接诊断和测试客户端仍禁搜索。每轮使用私有 stdio 进程，禁复用共享 daemon；配置覆盖只作用于本连接，不修改用户的 Codex 配置文件。

网页原生引用按本轮成功搜索输出转换为 Markdown 链接；未知/旧引用标明「网页来源未核实」，流式文字不会露出残缺的内部标记。普通 Markdown 链接仍按模型回复展示；引用转换不代表网页事实已获独立证实。规则要求只发送完成请求必要的公开搜索词/URL，但没有可以保证拦截所有个人信息的出站 DLP。

新增 Conversation.backend / codexThreadId、CodexTurn、CodexToolRun。schema-upgrade 自动补列、表与索引；桌面首次安装的 template.db 由既有 prepare 流程根据最新 schema 生成。旧 API 对话默认 api。
业务数据库备份仍按原流程；Codex 持久会话由 Codex 自己保存，平台数据库备份不包含完整 Codex 历史。换电脑仅恢复平台数据，不能保证原 thread 可恢复，界面会报告错误，不会自动建立空上下文冒充续聊。

## 验证记录

使用 Codex 0.162.1、隔离空白旧版数据库和虚构资料验收。生产构建、类型检查、双语检查及五项协议测试通过。
真实模型已完成：创建任务；下一轮记住口令、查询并修改任务；独立进程间恢复同一 thread；同一消息重试不重复写库；文本附件读取和归档；独立 HTML 生成、进度及页面保存。原 API 后端经本地 OpenAI 兼容模拟服务回归。
模型服务繁忙曾正确返回失败，未自动重放；后续只读附件验收使用测试模型继续。旧数据库自动升级、Next 重启后原 thread 续聊、取消轮次、服务重启后旧轮次标为失败且不自动重放已验证。刷新期间等待提示已检查；浏览器测试时标签页为 hidden，自动轮询完成的界面验收受后台休眠影响，恢复可见/焦点时会立即查询状态。手机 390px 设置和历史页面检查无横向溢出。

本次未重新逐一实测所有既有账单、体检、PDF/DOCX/XLSX 样本；它们复用原工具与解析器，并不代表所有模型/版本都已验证。打包后的安装版/绿色版仍须在明确发布时做完整安装、升级、退出与手机配对验收。

官方接入参考：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。动态工具协议为实验接口，安装的 Codex 版本不兼容时会报错；本地/开源认证与商业托管认证的范围以官方最新说明为准。
