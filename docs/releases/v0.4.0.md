# v0.4.0 本机 Codex 与任务专属对话

## 新功能

- 可选择本机已登录的 Codex 作为对话后端，保留 DeepSeek 等 API 模式。每个对话对应独立持续会话；通过平台工具查询与修改数据库。
- 本机 Codex 支持上传文件和独立 HTML 制作。无需填写 DeepSeek API Key，使用本机 Codex 登录对应的额度，仍需联网。
- 待办详情页新增「和 AI 聊这件任务」浮层；每件任务独立对话，带入最新要求、进展和关联资料，支持 API 与 Codex。
- 任务工具限制在当前任务；原要求保留，新进展追加，新增后续待办自动关联。收起后保留原页面位置，同页重开保留草稿。
- 修正 Windows 自动查找 Codex 时误选 npm shell 文件的问题。

## 下载与使用

- personal-ai-secretary-Setup-0.4.0.exe：安装版，推荐普通用户使用。
- personal-ai-secretary-0.4.0-win.zip：ZIP 免安装版，解压后运行。
- personal-ai-secretary-portable-0.4.0.exe：单文件免安装版，首次启动较慢。

升级前保留原 data 目录。安装版升级沿用用户数据；ZIP 版替换程序文件时保留 data 与 appdata，单文件免安装版保留 exe 旁的 data。旧数据库启动时自动补充新字段和表。

包内不携带 API Key、Codex 登录、个人业务数据。使用 Codex 时先在电脑安装并登录 Codex，再到「设置 → 对话后端」选择「本机 Codex」；已有对话保持原后端，切换后开启新对话。

## 发布验收

2026-10-14，Windows x64 / Electron 38.8.6 / Next 15.5.25。

- 生产构建、类型检查、双语检查及 10 项协议/任务范围测试通过。
- 三种 Windows 发布包均生成；运行时代码未包含 .env、API Key、私人数据或 Codex 登录。模板库为空且包含最新会话结构。
- 实际 ZIP 发布包启动、桌面设置保存与 Codex 登录诊断通过；Electron 自带 Node 调用本机 Codex 创建虚构任务，任务专属 thread 更新任务，保留最初要求并写入工具审计。
- 关闭并重开同一 ZIP 包后，原 Codex thread 和虚构口令保持连续。
- 安装包在隔离目录实际安装成功；安装版启动时自动升级带虚构资料的 v0.3.0 数据库，原任务、原始要求、API 会话和历史消息保留；数据库位于用户目录，卸载后仍保留。
- 实际单文件免安装包启动、读取已有测试资料、独立 Codex HTML 生成、进度和完整 HTML 保存通过。
- 正常关闭正在调用 Codex 的单文件应用后，12 个测试相关进程全部退出，内嵌服务端口关闭；未操作其他 Codex 会话或私人平台服务。
- 打包后的局域网网关验证未配对拒绝、配对码单次使用、任务页转发和 Origin 校验。没有代替用户在真实手机/防火墙环境中进行配对。
