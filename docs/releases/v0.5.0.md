# v0.5.0 语音输入、朗读与实时语音 Agent

## 新功能

- 录音输入：在主聊天或任务聊天点击麦克风，录音结束后由阿里云 ASR 转成草稿，编辑确认后发送。
- 回答朗读：将 AI 回答交给阿里云 TTS 合成，支持暂停、继续、停止和长回答分段。
- 连续语音：检测说话与停顿，自动完成 ASR → Agent → TTS，再恢复聆听。
- 实时语音 Agent：默认 `qwen-audio-3.0-realtime-flash`，支持 Plus；流式收音和回答、说话打断、后台执行业务及完成结果播报。查询和修改仍走原有业务 Agent，兼容 API 与本机 Codex。
- 改善网络抖动下的体验：上传缓冲与合并、按序号幂等重试、200–300ms 播放缓冲和连续播放时间轴；插话清空待播内容并忽略旧回答的迟到音频。
- 修复首次对话显示业务结果后意外关闭实时语音的问题；新增不包含音频和业务正文的时序诊断。

## 下载与升级

- `personal-ai-secretary-Setup-0.5.0.exe`：Windows x64 安装版。
- `personal-ai-secretary-0.5.0-win.zip`：ZIP 免安装版。
- `personal-ai-secretary-portable-0.5.0.exe`：单文件免安装版，冷启动需等待解压。
- `SHA256SUMS.txt`：三种程序的 SHA-256 校验值。

升级前备份原 data 目录。安装版覆盖安装并沿用用户数据；ZIP 版替换程序时保留 data、appdata 和自己的 config.json；单文件版保留 exe 旁相同目录。旧数据库启动时自动补充表与字段。本版本保留 v0.4.0 的本机 Codex、任务专属对话以及原 API 模式。

在「设置」中分别配置 ASR、TTS、实时语音服务，服务区域需匹配密钥。实时语音不调用独立 ASR/TTS 路由；选择本机 Codex 不会免除云端语音服务的配置与费用。详见 [实时语音](../实时语音对话.md)、[录音输入](../语音输入.md)、[回答朗读](../语音朗读.md)、[连续语音](../连续语音对话.md)。

包内不携带 API Key、个人业务数据或 Codex 登录。使用语音时音频或朗读正文会发送给对应的阿里云服务；原始录音不持久保存，转写和执行结果按聊天及执行记录保存在本机。

## 验证范围与已知限制

2026-10-15：语音、传输、播放、聊天历史、任务范围及 Codex 协议共 63 项自动测试通过，类型检查、双语检查与隔离生产构建通过。此前独立数据库上的真实 Edge → Flash 音频、插话、后台 Agent → SQLite → 结果播报链路已验收；模拟抖动连续播放、取消缓冲和迟到音频不复播通过。

Windows x64 / Electron 38.8.6 / Next 15.5.25 发布包验收：

- 安装版、ZIP 和单文件版均生成；实际打包运行时扫描 2,409 个文件，未发现本机密钥、个人数据库、环境文件或 Codex 登录。空模板库包含 22 张表及最新 VoiceJob 结构。
- 从实际 ZIP 附件解压启动，使用 v0.4.0 空模板加入虚构任务与聊天历史，启动后自动补齐 VoiceJob，原任务、原始详情和历史消息保留。
- ZIP 内实际点击录音，虚拟麦克风音轨进入 live；取消后进入 ended，其他收音入口恢复。设置页的 ASR、TTS、实时语音独立配置可用，默认 Flash、密钥为空。
- 单文件免安装附件实际解压启动，使用 exe 旁独立数据目录；虚拟麦克风采集及释放通过。两种免安装测试窗口正常关闭后，测试进程全部退出，内嵌服务端口关闭。
- 安装程序及内嵌 app-64.7z 载荷完整性检查通过。本轮未重新安装到系统，未覆盖用户现有安装或快捷方式。
- 构建与验收均在隔离目录完成，原网页服务继续运行。真实云服务链路的验收范围沿用上述独立浏览器测试，本轮打包验收未调用付费语音接口。

已知限制：

- 缓冲和重试用于缓解抖动。长时间浏览器验收仍出现过上游长连接中断，原因尚未确认；150 秒直接 WebSocket 对照未复现，不能视为已彻底解决断线。
- 真实手机、Safari、耳机、扬声器及嘈杂环境尚未完成全面实机验收。手机录音需要 HTTPS；桌面普通 HTTP 局域网访问不保证手机语音可用。
- 实时语音仅在前台持续运行，切后台、离开页面或音频设备失效会结束；单次会话最多 30 分钟。
- 插话停止当前回答，不撤回已接受的后台业务。服务重启不会自动重放未完成的业务操作，部分修改可能已经保存。
- Windows 程序未使用付费代码签名，也没有自动更新。

## English

v0.5.0 adds editable ASR voice input, TTS read-aloud, turn-based continuous voice and realtime voice with interruptions and background agent work. The default realtime model is `qwen-audio-3.0-realtime-flash`. Configure the Alibaba Cloud voice services separately in Settings, including when using local Codex.

Back up your data before upgrading. Keep data, appdata and your config.json when replacing portable builds. Packages include no API keys, personal records or Codex login. Audio/text is sent to the selected cloud voice service. Upload retries and playback buffering reduce jitter; occasional upstream disconnections remain unresolved. Mobile microphone access requires HTTPS; mobile/Safari and noisy environments have not been fully validated.
