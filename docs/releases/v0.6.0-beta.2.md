# v0.6.0-beta.2 Gmail 桌面测试版

本版将 Gmail 只读连接、邮件分析、候选提醒和手动转待办加入 Windows 桌面发布包。内置 Google Desktop 应用配置，打开「邮件」后直接点击「连接 Gmail」，无需自行创建 Cloud 项目或导入 JSON。

**这是预发布测试版。内置 Google 应用处于 Testing，仅测试名单中的账号可以授权，其他账号会被 Google 拒绝。** 本版不表示已完成面向所有 Google 用户开放的审核，稳定版继续保留 v0.5.0。

## 连接和使用

1. 在「邮件」中点击「连接 Gmail」，在运行 App 的电脑上通过系统浏览器完成授权。
2. 返回 App 核对邮箱。邮件分析、定期检查和桌面通知默认关闭。
3. 确认当前分析服务，明确允许该服务分析邮件并保存，再手动同步或开启定期检查。
4. 核对线索中的原文证据，由用户决定处理、忽略或转为待办。同一线索重复转待办不会重复建任务。

高级用户可导入自己的 Desktop OAuth 配置。自备配置优先于内置配置，升级不会覆盖；未连接时可切回内置配置。Google Testing 下 Gmail 刷新令牌通常 7 天过期，需要重新授权。

## 数据和权限

- 只读 Gmail，不发送、删除、标记已读或修改标签；首次范围为最近 7 天，每批最多 20 封。
- 邮件正文最多 12000 字符，附件仅列名称。开启 AI 分析后，正文发送至用户选择的 API 或本机 Codex 后端，使用该用户的额度。
- 本机保留摘要、证据与处理记录，邮件内容不能调用平台业务工具；转待办必须由用户点击。
- 应用退出或电脑休眠时暂停检查；本版没有托盘常驻、开机运行或手机推送。
- 断开会清除本机 Gmail 凭据和邮件台账，保留已创建任务。每个人的邮箱令牌独立保存在本机。
- 安装包有意包含可分发的 Desktop 应用参数，可被提取，不能当作保密的服务端密钥。包内不包含邮箱令牌、Cloud CLI 登录、模型密钥或开发者的个人数据。

## 下载与升级

提供 Windows x64 安装版、ZIP 免安装版、单文件免安装版及 SHA256SUMS.txt。升级前备份数据；安装版沿用用户数据，免安装版替换程序时保留 data、appdata 和自己的 config.json。

具体连接和构建方法见 [Gmail 桌面试点](../Gmail桌面试点.md)。本版保留 v0.5.0 的语音功能。

Windows x64 安装版、ZIP 版和单文件免安装版已构建完成，安装版与单文件包归档完整性检查通过。实际 ZIP 和单文件版启动后确认内置连接可用、无需导入 JSON，并可正常退出；ZIP 的 390px 窄屏无横向溢出，并验证虚构线索转待办及重复操作不会重复建任务。断开后本机账号目录和邮件台账已清理，创建的待办仍保留。包内容审计确认 22 张业务表为空，不含邮箱令牌、Cloud CLI 登录或模型密钥；仅包含有意分发的 Desktop 应用参数。

真实 Google 邮箱授权仍待测试用户完成；长期运行、分析效果及 Windows 通知送达也需继续验收。本次打包验收未读取真实邮件或调用付费模型。

## English

This prerelease adds Gmail read-only connection, AI findings, optional scheduled checks and explicit task creation to the Windows packages. The built-in Desktop OAuth configuration removes the JSON import step, but **Google Testing still restricts authorization to accounts on the test list**. Other users can import their own client configuration under Advanced. The stable release remains v0.5.0.

Analysis, periodic checks and notifications are off by default. Mailbox tokens stay on each user's computer. Enabling analysis sends mail bodies to the selected model service using that user's allowance. The distributed native-client parameters are extractable app identity, not mailbox authorization or a confidential server secret. Back up data before upgrading. Real-account and notification delivery testing remains a separate acceptance step.
