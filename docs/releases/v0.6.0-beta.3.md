# v0.6.0-beta.3 · Pi 与 Codex 对话能力升级

本版集中交付近期的对话改造：API 用户可以使用内置 Pi 管理多轮会话、工具循环与上下文压缩；Codex 用户继续使用独立持久线程。两条链路共用平台业务、附件、原文与引用工具。

这是 Windows x64 预发布测试版。内置 Gmail Google 应用仍处于 Testing，仅测试名单中的账号可以直接授权；其他用户可在高级设置导入自己的 Desktop OAuth 配置。稳定版 v0.5.0 继续保留。

## 主要变化

- **DeepSeek + Pi**：全新安装默认使用内置 Pi，模型预设为 DeepSeek 官方 `deepseek-flash`。填写自己的 API Key 即可使用，不需要另外安装 Pi。已有对话保留原后端，不自动导入或重建历史。
- **按需搜索**：Pi 可通过独立开关启用 DeepSeek Search/Fetch，官方聊天接口可复用聊天 Key；搜索有独立调用费用。Codex 搜索使用自己的登录及额度，开关与 Pi 独立。默认均关闭。
- **文件与业务原文**：支持按归档附件 ID 分页读取文字、Word 结构/修订/批注和嵌图、归档图像及扫描 PDF 指定页/裁剪区，并生成可下载文件。读取执行权限与版本核验，回答可附来源引用。图片理解需要支持视觉的模型。
- **长对话**：历史按页增量加载，保留阅读位置、草稿和附件，减少长聊天输入与滚动负担。
- **后台标题**：Codex/Pi 通用对话成功交流两轮后独立生成标题，支持重启恢复和手动重新生成。手动改名优先，不因标题更新改变会话排序。
- **聚焦文字体验**：暂时隐藏阿里云聊天预设和全部语音入口、朗读按钮及语音配置。保留底层服务、代码及已有设置；既有百炼配置在通用接口表单中原样展示。语音留待下一阶段推进。

## 下载与升级

提供安装版、ZIP 免安装版、单文件免安装版，以及 `SHA256SUMS.txt`。建议先备份数据再升级。

- 安装版保留已有用户数据目录；程序文件和数据库分开存放。
- ZIP 与单文件免安装版升级时保留自己的 `data/`、`appdata/` 和 `config.json`，不要用空模板覆盖已有数据库。
- 仅全新数据库默认选择 Pi。原 API、Pi、Codex 会话和用户选择继续保留；切换 API 地址或模型后，Pi 会要求新建对话以保护原会话。
- 所有公开包均不附带开发者模型 Key、邮箱令牌或个人数据库。用户自行填写模型 Key。内置 Google Desktop 应用参数是可分发的客户端身份，不是邮箱授权。

## 使用边界

- Pi 与 Codex 的核心平台工具基本一致，但上下文实现、模型推理与回答效果不保证相同。旧 Codex 线程保留原工具档案，需要新建会话才能获得部分新增工具。
- 本轮未加入向量/语义检索、跨事项语义参考、LibreOffice Word 整页渲染或 Python/pdfplumber。包内不要求这些运行时。
- 阿里云搜索与网页读取只完成隔离试点，未接入产品；本版 Pi 搜索仍使用 DeepSeek。
- Gmail 的真实账号授权、长期后台检查和系统通知送达仍受账号、Google Testing 及 Windows 环境影响。默认不启用邮件分析和定期检查。
- 安装包未签名，Windows 可能提示未知发布者；尚无自动更新功能，需要手动下载替换。

## English

This Windows x64 prerelease brings the embedded Pi harness, persistent conversations and compaction, optional DeepSeek search, shared file/source tools, incremental history loading and durable automatic titles to the desktop packages. New installations default to Pi with the official DeepSeek preset; existing data, backend selections and conversations are preserved. Alibaba chat presets and all voice UI are temporarily hidden while their implementations remain available for a later phase.

Bring your own model key. Public packages contain no developer model keys or personal data. The bundled Google Desktop client remains in Testing and only permits listed testers; other users may import their own Desktop client. Back up data before upgrading. Semantic retrieval, LibreOffice and Python table tooling are deferred. The stable v0.5.0 release remains available.
