# v0.6.0-beta.4 · 设置简化与家庭成员列表

本版在 beta.3 的对话能力基础上整理设置流程：减少需要理解的配置项，让 Pi / Codex 选择、家庭成员编辑和手机访问入口更清楚。

这是 Windows x64 预发布测试版，提供安装版、ZIP 免安装版和单文件免安装版。内置 Gmail Google 应用仍处于 Testing，仅测试名单中的账号可直接授权；其他用户可导入自己的 Desktop OAuth 配置。稳定版 v0.5.0 继续保留。

## 主要变化

- **设置分组**：按「AI 设置」「通用」「连接与安全」分成三个标签，切换标签保留未保存输入。
- **明确选择对话后端**：用单选项选择内置 Pi 或本机 Codex，只显示当前后端的配置。点击底部「保存并用于新对话」，检查通过后一起保存配置和默认后端；失败保留原配置，已有对话保留原后端与历史。
- **精简 DeepSeek 配置**：官方预设默认只需填写 API Key，模型与地址放入「高级配置」。Pi 上下文窗口固定为 128000，不再要求用户配置。
- **默认按需搜索**：Pi 与 Codex 的公开网络搜索默认启用，不再提供设置开关，旧的关闭设置不再生效。DeepSeek 官方聊天和搜索复用聊天 API Key，不再需要搜索专用密钥；搜索仍单独计费。Codex 使用本机登录及额度。标题、页面生成和连接测试不启用搜索。
- **家庭成员列表**：「家里的人」改为每人一行，支持添加、改称呼、移除和「设为自己」，统一点击保存生效。保留至少一人，检查空白和重复称呼；改名或移除不会修改已有任务的负责人。
- **手机访问入口**：桌面设置页提供「打开手机访问设置」按钮，打开原生开关与配对窗口；通过浏览器访问时明确提示使用电脑上的桌面程序菜单。仅打开窗口不会开启局域网访问。
- **深色下拉菜单**：明确设置原生下拉选项的文字与背景颜色，改善深色模式可读性。

## 下载与升级

从同页附件下载所需版本，并可使用 `SHA256SUMS.txt` 校验。

- 安装版：程序文件与用户数据库分开保存，升级保留原用户数据目录。
- ZIP 与单文件免安装版：升级前备份，保留自己的 `data/`、`appdata/` 和 `config.json`，不要用空模板覆盖已有数据库。
- 新安装默认内置 Pi + DeepSeek。已有配置和 API / Pi / Codex 会话保留；切换后端用于新对话，不迁移旧会话。
- 公开安装包不附带开发者模型 Key、邮箱令牌或个人数据库；使用者自行配置 Key 或登录本机 Codex。内置 Google Desktop 应用参数是可分发客户端身份，不包含用户邮箱授权。

## 使用边界

- beta.3 的文件原文、引用、长对话和后台标题能力继续保留。本版未加入向量检索、LibreOffice 或 Python/pdfplumber。
- 阿里云聊天预设和全部语音 UI 继续暂时隐藏，底层实现和已有配置保留。
- 网络搜索需要联网，DeepSeek Search/Fetch 按调用计费；自定义兼容服务不保证具备相同搜索能力，不会把其他服务商的聊天密钥发送给 DeepSeek。
- Gmail 内置客户端仍受 Google Testing 限制，邮件分析与定期检查默认关闭。
- 安装包未签名，Windows 可能提示未知发布者。尚无自动更新，需要手动下载安装。

## English

This Windows x64 prerelease reorganizes settings into AI, General, and Connections & security tabs. Choose embedded Pi or local Codex, configure only that backend, and save the checked configuration and default together. The official DeepSeek preset needs only an API key; model and endpoint are under Advanced. Pi's context window is fixed at 128000.

Public web search is now enabled by default for both backends. Official DeepSeek chat and search share the chat key, with separate search billing. Household members are edited as individual rows with add, rename, remove, and set-as-you controls. The desktop settings page opens the native phone-access dialog directly; browser users see clear desktop instructions.

Existing data, saved configuration and conversations are retained. Back up portable data before upgrading. Public packages contain no developer model keys or personal data. The bundled Gmail client remains in Google Testing. Voice UI remains deferred; stable v0.5.0 is still available.
