# 任务专属 AI 对话

2026-10-13。已同步到当前源码；已发布的 v0.3.0 安装文件尚不包含。本轮未打包或发布 Release。

## 使用

任务详情页点击「和 AI 聊这件任务」。电脑上打开右下角浮层，手机上在底部显示；聊天内部滚动，输入框固定，原任务页面不改变排版、不锁定背景滚动。点「收起」或 Esc 回到原任务，同页重新打开保留草稿和附件选择。回复完成及收起时刷新任务资料；关闭浮层不会中断同页已发送的请求。

每件任务使用唯一持久 Conversation，与通用对话及其他任务独立，不出现在通用对话列表。首次打开采用设置中的默认 API/Codex 后端；之后保持这个后端，切换默认不会自动转换旧历史。刷新或重新打开可查看已保存的历史，较早消息可继续加载。

旧式 /tasks/<id>/chat 链接与任务会话的 /chat/<conversationId> 链接会回到任务详情并打开浮层。

## 上下文与工具

每轮重新读取任务标题、最初要求、状态、负责人、优先级、截止日、结果、最近业务留言、关联文稿/专题、前置与直接后续任务以及附件元数据。长资料会截取，不保证完整载入所有原文。附件元数据不表示已阅读原件；需要分析文件时在聊天中重新上传，沿用原有文本、图片、PDF/DOCX/XLSX 解析能力。

服务端依据 Conversation.taskId 确定范围，不接受模型或客户端通过参数改换任务：

- listTasks 只读当前任务及直接关联的上下文。
- updateTask 只能修改当前任务的标题、状态、处理结果、优先级、截止日和负责人；不会覆盖最初的 detail。修改另留一条任务进展，和修改在同一事务中提交。
- saveNote 把用户要求保留的新要求或结论追加到任务经过。普通聊天单独留在任务会话，不把每句话重复铺进业务时间线。
- createTask 新建后续待办，并将当前任务设为它的前置任务。
- saveFile 与未被认领的上传附件关联当前任务，同时保留在文件页。

资料库、财务、健康、保单、页面制作等其他业务操作在通用对话完成。范围由服务端工具集合与参数校验执行，不能只靠提示词约束。

Codex 沿用独立持久 thread、后台队列、消息去重、工具审计、取消及重启中断处理。刷新/关闭网页后，已接收的 Codex 轮次继续；API 后端仍沿用原来的流式行为，刷新时不承诺同样的后台恢复。仅收起浮层时，两种后端均保留挂载和正在进行的请求。

## 实现与验证

Conversation 新增可空且唯一的 taskId 外键。普通历史保持 null。schema-upgrade 自动补列、索引；首次打开才建任务会话，不会因为列表默认预览或手机隐藏详情而批量建空对话。

私人版参考提交：1e1a0e5（独立会话及任务工具）、ff8efad（详情聊天入口）、7254167（保留原页面排版的浮层）。开源版复用既有 Conversation、AI SDK 与 API/Codex 接入，不复制私人版后台服务或家庭数据。

在完全空白的旧版数据库和虚构任务中验证：自动升级；一任务一会话的唯一约束；API 查询/修改、后续任务关联及追加进展；拒绝跨任务修改、会话任务不匹配和覆盖最初要求；真实 Codex 两轮修改与记忆、读取其他入口刚更新的结果；原 detail 不变、工具审计成功。
