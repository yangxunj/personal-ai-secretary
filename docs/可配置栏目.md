# 自定义栏目（源码试点）

2026-11-02。此功能尚未包含在 v0.6.0-beta.4 已发布安装包中；下一次桌面打包后交付。设计及后续阶段见 [实施计划](可配置栏目实施计划.md)。

## 如何使用

桌面宽屏点击侧栏「栏目」，或在「设置 → 通用」点击「管理栏目」。手机从底部「更多」进入；文件、页面和邮件也集中在这里，前六个常用入口保留。

可以选择空白栏目，或使用以下模板：

| 模板 | 创建的空栏目 | 关联 |
| --- | --- | --- |
| 客户跟进 | 客户档案、客户联系记录 | 联系记录指向客户 |
| 宠物档案 | 宠物档案、宠物照护记录 | 照护记录指向宠物 |

模板都是普通配置，创建后可以继续修改，不会插入示例业务记录。系统根据字段定义生成表单、表格和卡片，不为每个场景单独写一套界面。

## 可配置内容

- 栏目名称与说明、默认表格／卡片视图、记录标题字段。
- 最多 20 个字段：短文本、长文本、数字、日期、单选、勾选、关联记录；可设置必填，单选每行填写一个选项。
- 关联字段指向另一个已启用的自定义栏目，选择器可以按关键词查找记录。
- 栏目启用／停用。停用隐藏动态导航并拒绝记录工具读写，但目录中仍可配置、重新启用；不删除数据。

记录可以新增、编辑、按关键词查找、分页查看，以及归档／恢复。日期目前只是数据，不会自动产生提醒。每个栏目第一阶段上限 2000 条记录（含归档），最多 100 个栏目（含草案）。复杂看板、时间线、统计、附件字段及提醒规则属于后续阶段。

字段 ID 与显示名分开保存，改显示名保留原值。已有记录使用的字段不能删除、改类型或改关联目标；新增必填字段、移除仍在使用的选项等变更，如果无法通过已有记录校验，会整笔拒绝。旧定义保存在版本表中；当前不提供有损迁移和回滚界面。

记录与栏目定义均有版本保护：如果页面或 AI 持有旧版本，不会覆盖后来保存的修改，应刷新并检查当前数据后重试。普通自定义字段没有资料库的敏感值打码功能；账号、密码等继续使用原有资料库。

## AI 如何使用

通用对话使用少量固定工具发现栏目、读取定义、查询／读取记录、新增、局部修改和归档记录。字段名与关联目标从定义读取，所有写入由服务端按类型及启用状态校验。查询只返回有限预览，完整记录需要另行读取；成功回执带记录链接。

用户要求建立新栏目时，AI 可以提议草案并返回审阅链接。草案尚未启用，用户检查字段后点击「确认创建栏目」。AI 不直接启用草案或替用户确认定义。

- Pi 及旧 API 的通用对话支持这些工具。
- 新建 Codex 对话使用 v4 工具档案，之后新增栏目不再需要添加新工具名。
- 升级前已有的 Codex 线程保留原来的 v0–v3 工具及记忆，需要新建对话才能操作自定义栏目；不自动重置旧线程。
- 任务专属对话保持原范围，不增加跨栏目写入权限。

停用栏目只限制之后的工具操作，不会清除历史消息和模型已经见过的内容。既有财务、健康、待办等继续使用原专门工具与数据，不自动复制进自定义栏目。新通用表随数据库一起备份，不改变页面沙箱及 PageData 的已有行为。

## 技术与验收

通用表为 `CustomCollection`、`CustomRecord`、`CustomCollectionVersion`。Prisma schema 与桌面老库升级 SQL 同步；模板不另建领域表。所有写入复用平台事务，先取得 SQLite 写锁再检查启用状态和版本；Agent 继续复用执行审计与重复调用保护。

在隔离旧模板数据库上验证补表幂等、原任务数据保留、字段类型与日期校验、关联越界拒绝、过期版本拒绝、停用限制、重命名保留数据、记录上限和工具预览。

使用真实 Pi SDK 与合成 SSE 验证“读取定义 → 新增 → 局部修改”多步工具循环，确认 UI 与 Agent 服务读取同一份记录，重复工具调用不重复创建。未调用真实付费模型或使用正式数据库。

真实浏览器验收包括客户／宠物模板、从空白配置书单、字段改名、数字与勾选保存、关联记录、归档恢复、停用再启用，以及手机入口和浅深色布局。当前不代表新版安装包已经发布。
