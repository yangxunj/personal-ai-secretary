# 安卓对话中的幻灯片快捷入口验收

适用版本：0.26.0。建议覆盖安装现有测试版，不要先卸载，以保留本机数据。

1. 打开应用，确认原有对话和待办仍在。
2. 在对话中请 AI 创建一份知识幻灯片，等待回答完成。
3. 确认 AI 的回答气泡内出现“打开幻灯片：标题”，点击后直接进入刚创建的幻灯片，检查标题、内容和翻页。
4. 返回对话，重新打开该历史对话，确认入口仍可点击；关闭并重新打开应用后再检查一次。
5. 若曾在旧版本创建幻灯片，可检查对应历史对话：有完整成功回执时也会显示入口。

目前快捷入口仅支持幻灯片；其他模块的入口尚未接入。如果目标内容已经不存在，点击后应留在对话并显示提示。
