# 安卓栏目管理试点验收

适用 0.27.0。请覆盖安装，不要先卸载，以保留设备上的数据。

1. 在设置中找到“栏目管理”。初始时待办和知识幻灯片均开启，待办显示在底栏，幻灯片位于“更多”。
2. 开启知识幻灯片的“显示在底栏”，确认底栏出现幻灯片；放不下的其他入口可在“更多”找到。取消此项后，幻灯片仍可从“更多”进入。
3. 关闭知识幻灯片，确认底栏及“更多”均不再显示其入口；打开之前创建幻灯片的对话，点击历史快捷入口，应提示先开启栏目。
4. 新开一轮对话，要求创建知识幻灯片；关闭状态下应不能创建。回到设置重新开启后，检查之前的幻灯片仍在，并再次通过对话创建及打开一份。
5. 关闭待办，确认任务入口隐藏，新一轮对话不能添加待办；重新开启后，原有任务仍在，可继续通过对话添加任务。
6. 关闭并重新打开应用，确认栏目开关与底栏设置保留。检查原有对话、书单与待办数据仍在。

开关目前只控制安卓端的待办和知识幻灯片；设置仅保存在本机，不同步到其他设备。历史对话仍保留，包括之前的讨论内容。开关作用于后续工具调用，不会删除以前保存的数据或撤销已完成操作。
