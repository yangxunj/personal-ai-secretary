# 安卓知识幻灯片试点验收

本试点允许在安卓通用对话中请求 AI 生成简短的知识幻灯片；AI 将 Marp Markdown 保存在本机数据库，可从「更多 → 知识幻灯片」查看和翻页。生成依赖已配置的 DeepSeek API，可能产生费用。手机本地保存不等于与电脑或其他设备同步。

## 安装与测试

1. 覆盖安装 0.25.0，不要卸载旧版。先确认原有聊天和待办仍在。
2. 在「对话」输入一条明确请求，例如「请制作一份 3 页的光合作用知识幻灯片，面向初学者」。等待 AI 回复创建成功；如提示中断或失败，先检查幻灯片栏目，避免重复生成。
3. 点击底部「更多」→「知识幻灯片」，打开刚才的条目，逐页点击上一页、下一页，确认标题、内容和页数合理。
4. 返回列表，关闭并重新打开应用，再进入栏目查看记录。检查原有待办和对话仍可用。
5. 可以再换一个知识点验证。联网信息仅以 AI 实际调用搜索工具和给出的来源为准，不应假设所有内容都经过联网核实。

## 首版边界

- 当前为简短、文字为主的 Marp 幻灯片；不支持图片、外部链接交互、自定义 HTML、复杂数学排版、导出 PPTX、编辑、删除、原项目历史迁移或跨设备同步。
- 生成沿用现有手机对话请求：请保持应用在前台直至完成。未实现独立后台队列、断点续做或重试自动恢复。
- 列表和查看使用手机本地数据库；升级只新增幻灯片表，不应删除旧数据，但真实手机覆盖升级仍需实测。
- 生成完成、页面可看不代表知识内容正确。特别是时效性信息和专业内容应核对来源。
