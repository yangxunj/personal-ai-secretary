- 新 `src/components/chat/shared/ConversationListView.tsx` 共用列表展示、当前项与禁用状态；`conversation-list.ts` 原样抽取正式列表的本地日期分组和顺序规则。正式包装器保留Server Action、事件、乐观合并、Next Link与pathname；安卓包装器提供本地选择/新建回调。
- 新 `ChatTextInput.tsx` 共用受控文本输入、ref、粘贴入口和回车规则。正式Chat继续管理附件、语音、请求和发送按钮，安卓继续管理原生模型桥接、草稿与取消。
- 桌面Enter发送、Shift+Enter换行；触屏Enter换行。增加composition状态、native isComposing和keyCode229保护，避免中文候选确认触发发送。发送前仍检查canSend、disabled和readOnly。
- 安卓使用同一React组件替换下拉列表/手写textarea事件。原生列表仅增加返回现有updated_at元数据，不新增字段、不改会话快照。保存失败时停止发送、禁用列表并保留当前输入。
- 共享UI依赖检查、样式扫描、源码哈希和构建测试覆盖新组件；模型/密钥路径、依赖锁、正式数据库与私人项目未修改。

输入区外围的附件/语音/发送取消按钮未整体统一；安卓自动压缩、附件、同步、导出和任务专属模式仍未实现。没有发布网页/Windows正式安装包或部署生产服务。
