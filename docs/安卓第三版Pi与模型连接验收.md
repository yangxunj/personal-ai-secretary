## 安装与免费验收

[私人 Google Drive 下载第三版 APK](https://drive.google.com/file/d/1Z2oiY8dP4W2gKJNJ18WCK-ONUgdxHD64/view?usp=drivesdk)。直接覆盖安装第二版，不卸载、不清数据。包名、签名证书保持一致。

1. 打开后顶部显示 0.3.0，原书单及编辑结果保留。
2. 在“书单助手”保持默认的“离线演练”，点击运行。
3. 应显示“读取栏目定义”“创建记录”完成，列表新增一条“Pi离线演练书单”。这是固定模型替身，不是自然语言 AI，也不产生 API 费用。
4. 强停并重开应用，确认原书单与演练记录仍在；飞行模式下可以执行同样演练。
5. 原八项字段/共用写入规则检查继续通过。

一次点击只应新增一条演练记录；再次主动点击是新一轮，会再新增一条。工具回执去重保护的是同一轮同一工具调用，不能把它理解成按书名去重。

## 可选真实模型验收

仅在准备使用自己的 DeepSeek API Key 时进行。密钥直接填进应用原生弹窗，不需要发到聊天。本轮开发没有读取本机已有密钥，也没有调用真实收费接口。

1. 选择“DeepSeek Flash”，点击“设置模型密钥”，在原生密码输入框填写并保存。
2. 在请求框输入“在书单里添加《安卓AI测试》，状态想读”，点击发送。
3. 等待工具结果，确认列表确实出现记录；不能只以模型说“已保存”作为成功依据。
4. 输入“把《安卓AI测试》的状态改为读完”，应读取旧记录再修改，其他字段保留，且没有重复新增。
5. 请求期间可取消，或离开应用；不应继续发起新请求。已经提交的记录保留，不自动撤销，也不自动重发写入。网络/HTTP 错误后请求草稿保留。

模型为官方文档当前列出的 `deepseek-flash`，关闭 thinking，单次输出上限 2048 tokens，每轮最多 4 次模型请求/8 次工具操作。本轮请求、前 25 条书单和工具读取结果会发送给 DeepSeek，按服务商规则计费。回复一次性显示。没有验证密钥权限/额度；“已保存密钥”不代表实际模型请求成功。

本试点每轮独立，只有书单四种工具：描述栏目、读取记录、创建记录、修改记录。现阶段没有持久会话、自动压缩、跨轮恢复、流式文字、待办工具或完整秘书 UI；超过前25条的记录定位也尚未提供查询工具。不能将本包称为完整 Pi coding-agent 的安卓迁移。

## 实现与边界

- 直接运行已安装 Pi agent-core 1.4.0 的上游 `runAgentLoop`，没有复制或重写工具循环。浏览器入口仅重导出 Pi AI 所需的上游纯工具，避免加载文件凭据/模型发现等 Node 模块。
- TypeBox 采用其官方 `Settings.Set({useAcceleration:false})` 解释执行，CSP 保持无 `unsafe-eval`。构建锁定核心版本并记录上游循环文件哈希。
- `src/lib/collections/tool-contracts.ts` 为正式网页/Windows 与安卓共用工具描述和 Zod 参数；两端继续共用 `schema.ts`、`record-write.ts`。正式平台的 Prisma 事务、引用校验和原审计不替换。
- 安卓数据库版本 2→3 只新增 `tool_receipts` 表；业务写入和回执同一事务提交。同一调用 ID/参数返回原结果；同一 ID 换参数拒绝，避免取消或传输失败后的同调用重放。
- 原生层仅提供固定 `https://api.deepseek.com/chat/completions` 的 POST 请求，不允许传入其他 URL，不跟随重定向，不返回 HTTP 错误正文，不记录密钥。
- 密钥由 Android Keystore AES-GCM 加密后存入应用私有偏好，网页只能获取是否配置，不能读取密钥；关闭云备份并显式排除设备转移。密钥加密的真实设备结果仍待本轮验收，不以源码检查代替。
- WebView 仍只加载固定 HTTPS 本地资源，禁止 file/content 访问、远程页面、iframe 和网页网络。仅原生模型传输声明 INTERNET 权限。生成页面/附件未接入，不能把受信任桥接暴露给生成 HTML。

- 12 项安卓共用/Pi 检查：禁止动态代码生成下运行上游 Pi、模型替身工具闭环、无效参数拒绝、调用回执去重、取消前后写入边界、截断输出不执行工具等。
- 正式项目 12 项栏目集成测试，含原 Pi 工具循环；主项目 TypeScript 检查。
- 安卓应用/设备测试包离线构建；Android Lint 无错误，保留 1 条 `SetJavaScriptEnabled` 提醒（本地受信任 UI 必须启用 JS，来源/CSP/桥接边界另行限制）。
- 实际浏览器在 CSP 下完成固定演练；模型错误/取消替身验证草稿保留、按钮恢复与已保存记录不变；横竖屏无横向溢出，截图已查看。原生存储与模型连接在浏览器验收中均为合成替身。
- APK 签名有效，与第二版证书相同；无 `.env`、用户数据库、源码映射、原生 `.so`；包含项目、Pi、TypeBox、Zod 和 AndroidX 许可文件。
- 私人 Drive 元数据回读：文件名/MIME 正确，941718 字节，`shared=false`，权限只有 owner。

用户回执已证明该次真实 DeepSeek 请求与 AI 新增书单可用，不再以“模型连接待验”概括整版。仍待：修改/取消/切后台的逐项设备结果、重启后密钥保留、设备自动测试，以及重复工具 ID 的原生事务断言。开发阶段的浏览器演练仍不计为真实模型证据。
