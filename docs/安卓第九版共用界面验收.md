# 安卓第九版共用界面验收

适用版本：`0.9.0-pilot`。这次主要检查手机界面和覆盖升级；它仍是开发测试包。

1. 下载第九版 APK，直接选择更新安装。不要卸载旧版或清除数据；若提示签名不一致或无法更新，停止并反馈提示。
2. 打开后看对话页：页头、深浅主题、底部的对话／任务／资料／财务／健康／专题／更多，应与网页手机窄屏的设计一致。检查字体、按钮及底栏是否被系统状态栏或导航栏遮挡。
3. 切换对话、任务和更多，再回到对话，检查切换及选中状态。点击尚未接入的资料、财务等栏目，应显示“栏目正在适配”。书单仍可从“更多”进入。
4. 查看旧对话、书单和待办是否仍在。打开“对话列表”，切换已有会话；输入一段草稿，切换栏目后返回，确认草稿仍在。若之前配置过 DeepSeek，可以发送一条简单消息，检查回复和气泡显示。
5. 切换深浅主题，关闭并重新打开应用，检查界面和旧数据；如方便，在横屏下检查侧栏／底栏和内容是否可用。

本版共用网页的整体框架、导航、页头、主题、对话气泡和部分已有组件；安卓的对话、待办和书单仍使用现有试验功能。各栏目内部界面及功能尚未全部同步，设备间数据也不会自动同步。实际安装、键盘、安全区和触屏体验以手机验收为准。
