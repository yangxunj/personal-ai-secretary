# 安卓第八版精简测试指南

适用范围：`0.8.0-pilot` 测试版，建议使用此前已安装过秘书试验版的安卓平板。测试包是开发版，不是应用商店正式版。测试内容集中在最近新增的本地保存与待办操作，不需要重复以前的整套测试。

## 1. 覆盖安装与原数据

1. 从提供的私人网盘链接下载 `secretary-shared-pilot-0.8.0.apk`，直接点击安装并选择“更新”或“安装”。**不要先卸载旧版，也不要清除应用数据**；如果提示签名不一致或无法更新，停止操作并反馈提示。
2. 打开应用，确认顶部显示 `0.8.0`。查看此前的待办、书单和对话仍在；如果配置过 DeepSeek，确认设置入口仍显示已配置即可，无需发起付费请求。

## 2. 设置负责人并创建待办

1. 在“我的待办”展开“设置负责人名单”，输入两个测试称呼，例如 `我，测试成员`，点击“保存负责人”，确认显示保存成功。
2. 在新建待办里填写测试标题、原始要求，并将负责人选为“测试成员”，点击“保存待办”。确认新任务出现，显示正确负责人和原始要求。

## 3. 修改与重新打开

1. 在这条任务卡片中，将负责人改为“我”，再改为“待定”；确认内容仍在。
2. 将状态改为“已完成”，在“查看范围”选择“已完成”，找到这条任务；再把状态改回“未开始”，在“未完成”中确认它重新出现。
3. 用负责人、分类或状态筛选一次，确认列表数量与看到的任务一致。

## 4. 重开与名单调整

1. 完全关闭应用后重新打开，确认负责人名单、测试任务、状态和原始要求仍在。
2. 把测试任务负责人设为“测试成员”，然后在名单设置中移除“测试成员”并保存。确认该任务依然显示原负责人，并仍能按负责人筛选到。
3. 如方便，横竖屏各看一次，确认文字与操作控件没有被遮挡。

请反馈每一步是否通过，以及异常发生在哪一步、屏幕提示是什么。名单和任务保存在应用本机；目前尚无完整导出恢复方案，因此测试期间请保留应用，不要卸载或清除数据。
