# 安卓第十一版输入区验收

适用版本：`0.11.0-pilot`。请直接覆盖安装，不要卸载旧版或清除数据；如提示无法更新，请保留旧版并反馈。

1. 打开对话页，确认输入框贴近底部导航栏上方，页面中不再显示“模型与设置”。
2. 点击输入框弹出手机键盘，输入文字，确认输入框、发送按钮和所输入的内容没有被键盘或导航栏遮住；收起键盘后再检查一次。
3. 查看一段较长对话，向上、向下滚动，确认消息和输入框都可使用。切换会话并返回，检查旧消息与未发送草稿。
4. 点击右上角设置，确认可以找到 DeepSeek 密钥入口及模型模式。已有密钥无需重新输入；如愿意，可返回对话发送一条简单消息验证。

本版主要调整安卓试验界面的布局和设置入口；键盘、安全区和覆盖安装的表现以实际手机验收为准。
