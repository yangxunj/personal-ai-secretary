# 安卓第十二版对话区域验收

适用版本：`0.12.0-pilot`。直接覆盖安装，不要卸载旧版或清除数据；若无法更新，请保留旧版并反馈。

1. 打开已有对话，确认顶部不再显示“DeepSeek 对话 · 轮数 · 保存在本机”；对话区域应从页头下方延伸到输入框上方。
2. 在较长对话中上下滑动，确认能看到最早的消息和最后一条回复，气泡不会被输入框或页头遮住。
3. 如果对话中有宽表格或代码块，尝试在内容内部横向滑动，再上下滑动对话，确认两种操作都可用。
4. 点击输入框弹出和收起键盘，检查消息和输入框；再切换对话、关闭重开应用，确认原有内容和草稿正常。

正常状态文字已隐藏，存储失败等需要处理的提示仍会显示。实际手机、键盘和覆盖安装效果以设备验收为准。
