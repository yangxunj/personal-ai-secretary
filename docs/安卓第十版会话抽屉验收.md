# 安卓第十版会话抽屉验收

适用 `0.10.0-pilot`。在已安装第九版的手机上直接更新，不要卸载旧版或清除数据；如果提示无法更新，请保留旧版并反馈。

1. 打开对话，点击左上角三条线：会话列表应从左侧弹出，后面的页面变暗。点击右侧暗色区域或抽屉右上角的关闭按钮，列表应收起。
2. 再次打开列表，选中之前的会话，确认列表自动收起、原有内容仍在。
3. 输入一段草稿，打开列表并新建对话，再切回原会话，确认草稿仍在。关闭重开应用后再查看一次已有对话。
4. 如方便，检查深浅主题及横屏：列表文字、按钮和手机系统栏不应互相遮挡。

本次只调整会话列表的打开方式与共用外观；原有安卓本地会话及其他栏目功能范围不变。手机上的覆盖升级和实际触屏体验需由设备验收。
