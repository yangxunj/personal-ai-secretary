# 安卓语音对话首版测试指南

0.24.0 测试主对话中的轮流语音：说完后点击「发送语音」，识别文字交给现有 Agent，AI 回答后朗读，播完继续聆听。每轮最多录音 60 秒，录满后等待手动发送。它暂不支持说话打断 AI，也还没有接入任务详情中的专属对话。语音服务使用阿里云百炼，可能产生费用。

## 安装与设置

1. 直接覆盖安装 0.24.0 测试包，不要先卸载；打开后确认旧对话、待办仍在。
2. 打开「设置」，确认原有 DeepSeek 密钥仍有效；点击「设置语音服务」，选择密钥所属区域，填写自己的百炼 API Key 并保存。语音密钥加密保存在手机上，不会显示到聊天中；请勿将密钥发给开发者。密钥须开通并有权限使用 `qwen3-asr-flash` 和 `qwen3-tts-flash`。
3. 回到「对话」，点击「开启语音对话」，出现系统麦克风权限提示时选择允许。

## 测试步骤

1. 先在输入框打上一段不发送的测试草稿。开启语音后说一句简单的话，例如“你好，请用一句话介绍自己”，说完点击「发送语音」。确认出现自己的文字气泡、AI 的回答气泡，并听到朗读。
2. 等朗读结束后再说一句追问，点击「发送语音」，确认不需要重新开启语音，仍能继续交流。语音期间原有草稿应保留；退出语音后输入框恢复可编辑。
3. 另用一条虚构内容，请 AI 创建一项测试待办。等回答完成后到待办列表确认只创建一次、内容正确。退出语音不会撤销已提交的任务；若中途出错，先检查待办再决定是否重试。
4. 再次开启语音，按 Home 键或切换到其他应用后返回，确认不会自动恢复收音；需要手动重新开启。
5. 如方便，分别用手机扬声器和耳机试一次；留意识别准确度、停顿、音量、回声和语速。

如开启失败或发送后没有文字，请记录屏幕上的状态和错误提示；新版会区分没有收到录音数据、收到的音频全是静音和没有识别到文字。不要在反馈中包含密钥。真实语音识别、费用、手机权限和播放效果以这次实机结果为准。
