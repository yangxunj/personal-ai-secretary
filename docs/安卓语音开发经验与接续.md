# 安卓语音开发经验与接续

记录日期：2026-11-12。用户决定暂缓语音功能，转向其他工作；本文记录已确认的结果、未确定的问题和以后恢复时的入口。

## 当前结果与边界

- 用户在小米 14 上反馈 0.24.0 语音测试成功。该版在主对话中开启语音后，用户说完手动点击「发送语音」；设计上 AI 朗读结束后再次聆听，每轮仍需手动点击发送。
- 本次反馈未逐项确认不同网络、耳机、嘈杂环境、长时间运行、切后台、覆盖安装后数据保留以及语音操作待办等全部场景，不能把一次成功写成这些项目均已验收。
- 任务专属对话的语音和阿里云实时双向语音尚未接入安卓。实时模式的插话和后台结果回执也不属于当前手机版本。
- 用户认为之前自动结束不工作可能与背景声音或停顿检测有关；这只是合理猜测。之前停在「正在聆听」还可能是音量、检测阈值、录音数据或其他原因，尚无证据锁定根因。手动发送绕过自动结束条件，并不单独证明是哪一种原因。

## 已确认的排查过程

1. 0.20.0：用户允许麦克风权限后仍出现笼统的语音启动失败提示。仅凭当时文案无法区分录音权限、音频上下文与音频模块加载等步骤。
2. 0.21.0：增加音频模块加载失败后的备用处理及按步骤报错；小米 14 提示无法启动录音。
3. 0.22.0：收窄到 `getUserMedia` 返回 `NotReadableError`。用户确认手机系统录音机能正常录音，因此不能断言手机麦克风硬件有问题，也不能仅凭异常名称断言其他应用占用。
4. 0.23.0：WebView 录音不可读时增加安卓 `AudioRecord` 备用采集。用户反馈不再报启动错误，但一直显示「正在聆听」，说话后无文字；这只说明启动流程没有提示失败，并不证明每个采集样本或自动检测条件正常。
5. 0.24.0：安卓主对话改为用户手动结束本轮。增加「发送语音」，内存中缓存最多 60 秒的音频；满时停止向本轮录音追加音频并等待发送。未收到音频、录音过短、全零静音和识别结果为空分别提示。用户随后反馈测试成功。

## 架构和使用约束

- 网页、Windows 和安卓复用 `src/components/chat/VoiceConversation.tsx`、语音检测、WAV 编码、朗读文本处理及 Agent 业务逻辑；安卓通过平台适配提供密钥、网络、系统权限和必要的原生录音。网页原有自动结束模式与安卓当前手动发送模式是同一组件的不同配置。
- 安卓 WebView 优先使用 `getUserMedia`；遇到指定的不可读取或不支持错误时，尝试 `experiments/android-shared/android/app/src/main/java/com/aisecretary/sharedpilot/NativeMicrophone.java`。桥接代码为 `experiments/android-shared/web/native-microphone.mjs`。系统录音权限仍是必需条件；不会绕过用户拒绝权限。
- 手动录音由 `src/lib/voice-manual-buffer.ts` 在内存中暂存；用户点击发送后才提交该段音频。语音识别和朗读调用阿里云百炼，可能产生费用。密钥在安卓原生层加密保存，不写入仓库、聊天或安装包。
- AI 处理和朗读期间，WebView 音轨静音，原生备用通道不向界面转发音频；退出或切后台时释放录音。原生通道在暂停转发期间仍可能持有录音设备，不能把它描述为设备层面已停止采集。
- 测试时避免记录密钥、语音内容和个人对话。错误诊断优先提供阶段和受限的错误类型，而不是透传服务商原始错误。

## 经验与以后接续

- **验证到目标环境。** 本地构建、单元测试和桌面浏览器模拟通过，并不等于 Android WebView 的麦克风权限、采样或实际播放可用。语音问题需要区分模拟结果与手机实测；有设备时优先补测系统权限、AudioRecord 和 WebView 实际链路。
- **先区分阶段。** 授权、打开麦克风、获取音频帧、发声检测、识别、Agent 和朗读各自可能失败。今后排查先确认界面停在哪一步，以及是否收到音频或全零静音，不将所有异常归因于权限或麦克风占用。
- **保留用户的明确控制。** 手机上的手动发送是用户提出并测试成功的工作方式。若以后恢复自动结束，应作为可选择的模式，保留手动发送，使用真实手机、安静和背景噪声场景调试阈值，不因推测直接替换现有模式。
- **避免重复执行。** 对已交给 Agent 的任务，退出语音不代表撤销；异常后先检查聊天和待办，再决定是否重试。录音、临时状态和工具调用不应污染最终聊天气泡。
- 恢复工作时先读 [实施计划](安卓语音对话实施计划.md)、[0.24 测试指南](安卓语音对话首版测试指南.md) 和当前代码、Git 状态；以新实测结果更新结论，不把旧的桌面模拟或旧版本状态当成当前手机验收。
