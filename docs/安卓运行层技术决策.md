# 安卓运行层技术决策

更新日期：2026-11-04。状态：前五版分别获用户通过反馈，第五版真实连续追问、历史/草稿重开、对话切换及取消后保留已确认。强停/后台/密钥恢复没有单独反馈。正式产品框架仍待共用UI/完整SDK会话接入后确认。

## 决定与原因

先将现有栏目校验源码构建为浏览器 JS，在 Android WebView 中直接执行；安卓 SQLite 适配器只处理持久化，不复制字段规则。主应用继续使用原来的 Next.js/Prisma 路径，两边引用同一规则文件。

首包采用原生 Java Activity、AndroidX WebViewAssetLoader 与 SQLiteOpenHelper，减少未知依赖；没有引入自写 AI 编排、完整原生业务 UI 或远程秘书服务。试验的简单 HTML 页面用于检验数据链路；正式版本仍以共用 React 界面与应用服务为目标，不能把试验页面演变成另一套独立产品。

没有修改主应用依赖或数据库，安卓工程位于 `experiments/android-shared/`。首包运行和第二版覆盖升级/编辑已获用户通过反馈。正式栏目服务与安卓共用 `record-write.ts`；第三版又抽取四项共用工具契约，正式执行入口仍保留原事务、引用校验和审计。

第四版新增 `src/lib/tasks/contracts.ts`/`policy.ts`，正式 `agent-tools.ts` 与安卓共用通用任务规则。安卓独立 `tasks` 表只做平台投影，不复制成自定义栏目；任务专属范围/日期/原要求保护逻辑保持原路径。[第四版证据与限制](安卓第四版待办验收.md)单独记录。

## 内嵌 Node 候选的处理

Node.js Mobile 能将 Node 嵌入移动应用，但这不自动解决 Prisma、图片原生模块、Pi SDK 和生命周期兼容性。

- Prisma 官方系统要求列出 Windows、macOS、Linux 及 glibc/musl 条件，没有将 Android/Bionic 列为支持平台。此事实不证明所有替代引擎方案都不可能，但不足以支持“把现有 Prisma 直接打进去”。
- 当前安装的 Pi coding-agent 1.4.0 声明 Node `>=22.19.0`，依赖进程、文件会话及其他 CLI 组件。公开 Node.js Mobile 仓库读取到的源码记录包含 Node 18.20.4 更新，未核实出能承载本项目完整依赖链的现成受维护组合。未据此声称所有 Node.js Mobile 分支均只支持 Node 18。
- 本轮不投入完整原生引擎移植，以免为保留桌面运行时形成长期维护分叉。该候选按“缺乏可直接采用的兼容证据”退出本轮，没有伪造 Android 上的失败运行结果。

第三版已验证可直接运行 Pi agent-core 1.4.0 的上游 `runAgentLoop`，通过窄入口重导出它依赖的 Pi AI 纯工具；TypeBox 使用官方解释执行设置，无需放开 `unsafe-eval`。模型协议、网络和存储作为平台适配。完整 coding-agent 的文件会话、压缩、持久上下文和其他业务工具仍未迁移，不能把单轮试点当成完整 Pi 迁移。

## WebView 的边界

第五版沿用上游Pi循环和消息格式，将成功轮次存入版本化SQLite快照，恢复后作为上下文；中断不自动重发。纯模块 `src/lib/pi/conversation.mjs` 当前供安卓使用，正式SessionManager不改。Node与安卓共用的上下文估算提取到 `context-budget.mjs`，公式与SDK压缩配置保持；安卓自动压缩仍未接入。见[第五版验收与限制](安卓第五版多轮会话验收.md)。

- 使用官方 `WebViewAssetLoader` 的 HTTPS 本地来源加载打包资源，禁用 file/content 访问与混合内容。
- 仅允许本地固定来源和 `/assets/`，其余导航与请求拒绝；CSP 禁止网络、iframe、对象和内联脚本。第三版仅原生 DeepSeek HTTPS 传输启用 INTERNET 权限。
- 桥接提供受限记录操作/回执、固定模型请求和原生密钥设置，不提供任意 SQL、文件路径、shell、动态 URL 或密钥读取。密钥由 Keystore 加密并排除备份；原生桥接不接受远程/生成页面内容。
- 正式产品接入生成页面、附件和多模型时仍需重新审查异步桥接与来源隔离；不得把当前受信任桥接直接暴露给生成 HTML。第三版详见 [验证与边界](安卓第三版Pi与模型连接验收.md)。

## 固定版本与复现

第六版新增独立React UI构建入口，直接引用正式MessageBody组件；TSX自动JSX编译和生成样式复用现有依赖，无新增主应用依赖。消息挂载和链接拦截属于安卓适配，Markdown逻辑不分叉；核心逻辑bundle仍独立。包内附实际编译模块许可证及Tailwind许可，完整界面尚未迁移。详见[第六版验收](安卓第六版共用消息界面验收.md)。

Gradle 8.9 / AGP 8.5.2 / JDK 17 / SDK 34；WebKit 1.11.0；设备测试 runner 1.6.2、ext-junit 1.2.1。官方 AGP 8.5 要求至少 Gradle 8.7/JDK 17，支持的最大 API 为 34；本组合已实际构建通过。首次补齐 Google Maven/Maven Central 依赖后，离线构建也成功。

共享规则使用主仓库锁定的 Zod 和 TypeScript，打包器复用已安装 Next 附带的 webpack，未安装另一套前端依赖。该路径是试验期的复用方式；正式工程应显式管理打包工具版本，不能假设所有未来 Next 版本保留私有编译入口。
