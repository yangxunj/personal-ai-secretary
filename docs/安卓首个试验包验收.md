# 安卓首个试验包验收

日期：2026-11-03。版本 `0.1.0-pilot`。这是验证共用规则与本地存储的小型试验包，尚不是完整 AI 秘书安卓版本。

## 安装

[私人 Google Drive 下载 APK](https://drive.google.com/file/d/1egGylV0EDFIus26LjEcX_iGo-4-GlL1V/view?usp=drivesdk)。在安卓平板下载后打开；系统要求时，允许当前下载应用安装此来源的应用。

- 应用名称：**秘书共用逻辑试验**。
- Android 8.0（API 26）及以上，使用系统 WebView。
- 包名：`com.aisecretary.sharedpilot`，使用独立 SQLite 数据库；不连接电脑、无需模型密钥。
- 当前测试包没有网络权限，只填写合成测试内容。卸载会删除试验记录；本包尚无导出功能。

## 手工验收

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 打开应用 | 显示“我的平板书单”，无须启动电脑或填写服务器地址 |
| 2 | 填写“小王子”、一个日期及阅读状态，点击保存 | 右侧/下方列表出现记录，表单清空 |
| 3 | 展开“检查规则是否一致”，运行规则检查 | 六项均显示通过；这些检查不新增记录 |
| 4 | 从最近任务中关闭应用，再打开 | 原记录仍存在 |
| 5 | 在系统设置中强行停止该应用，再打开 | 原记录仍存在；这比仅关闭页面更接近进程结束验收 |
| 6 | 开启飞行模式，重开应用并添加另一条记录 | 正常显示、保存、重读，不需要网络 |
| 7 | 横竖屏切换，调出软键盘填写内容 | 文字和输入框可用，无横向溢出；尚未保存的草稿跨旋转暂不作为本包通过条件 |

步骤 7 的草稿跨旋转保留需要后续实现；本包优先验证已保存记录。覆盖升级与附件、AI 对话、Windows 包回归不在本次已完成范围。

2026-11-03 用户已安装并反馈：“测试全部通过，没有问题。”本表所列首包操作按用户实机反馈记为通过。未采集设备型号、安卓/WebView 版本或自动测试日志，不补写这些信息。

## 已完成的开发验证

- 应用及 AndroidX 设备测试包构建成功，完成一次最终离线构建。
- 五项自动检查通过：共享源码/包哈希、Node 与浏览器校验一致性、非法输入不写存储、写入失败不返回成功、存储接收规范化数据、试验包网络边界（部分检查在同一测试用例中）。
- 六组规则样例覆盖有效记录、必填、无效日期、非法选项、未知字段和长度限制。
- 浏览器以合成存储替身验证保存、列表刷新、失败保留草稿、按钮恢复；1280×800 与 800×1280 均无横向溢出，截图已查看。**这不是安卓 SQLite 或 WebView 实机验收。**
- APK 签名验证成功；检查产物仅包含白名单网页资源，无 `.env`、用户数据库、源码映射和原生 `.so` 库。
- Google Drive 回读确认文件名、MIME、643178 字节、`shared=false`，权限只有 owner。最终包补齐开源许可后原位更新，下载链接不变。

用户实机反馈已确认：首包安装/运行、本地记录保存与重开、强停恢复、飞行模式及规则检查通过。开发者仍未连接设备执行自动测试。覆盖升级、新版编辑和共享写入更新见 [第二版覆盖升级验收](安卓第二版覆盖升级验收.md)，尚不能将其算作已通过。
