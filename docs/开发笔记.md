# 开发笔记

写给想改代码的人：几块核心功能为什么这么做、实测踩过哪些坑。
桌面端（Electron 打包、数据落点、手机访问）另见 [`desktop/README.md`](../desktop/README.md)。

> 这个项目是从作者自用的私人平台分出来的。代码注释里的「主平台」指那边，
> 「主人」指使用者本人，「我」多半是写注释时的 AI 助手。

## 登录（只在自己架服务器时用得到）

桌面版只听本机、不做登录。把网页版放到服务器上给别人用时，**登录是唯一的防线**，所以有三处加固：

**1. 配置不全就拒绝服务**（`src/lib/env-guard.ts`）

常见的写法是 `process.env.SESSION_SECRET ?? ''`。secret 忘了设，
`verifySessionValue` 拿到空串照样算 HMAC —— 登录页正常显示，**但任何人都能用
空密钥自己造一个合法 cookie 直接进来**。内网下无所谓，公网下是全部隐私数据敞开。

这里不降级：缺一样就整站 503，宁可白屏也不要假装有防线。
真要在本地关掉登录，得显式设 `ALLOW_INSECURE_LOCAL=true` —— 让这件事
只能是故意的，不可能是手滑。

**2. 登录限流**（`src/lib/login-throttle.ts`）

不限次、不延迟、不锁定的登录接口，公网上就是主要攻击面。现在是递增延迟（第 n 次失败等 2ⁿ×250ms，封顶 8 秒）+ 连错 10 次锁 15 分钟。
实测：第 1 次 0.05s、第 6 次 8.06s、第 11 次直接锁定。

密码正确时也等同样的延迟 —— 否则用响应快慢就能反推密码对不对。

**3. 登录后跳转防开放重定向**（`src/app/login/actions.ts`）

`startsWith('/')` 一个条件拦不住 `//evil.com`（协议相对 URL）和 `/\evil.com`。

## 财务和健康：同一条路径

读图入库靠**模型的视觉能力**。两个模块因此长成了同一个形状：

```
用户传一张照片 / PDF  →  AI 读  →  写 JSON  →  CLI 入库  →  页面刷新
```

- 体检报告：`health:import <report.json> --attach <原件>`（`health-commands.mjs` 里没有解析器，只有入口）
- 账单：`finance:import <账单.json> --attach <原件>`（不认任何一家银行的版式，谁家的账单都行）

DeepSeek 的 `deepseek-flash` 支持图片输入，每张最多 1024 token、自动缩到
1300×1300 上下，读体检报告和账单够用。

**代价是数字由模型读出来，会读错。** 所以 `finance:import` 入库时做一次
**余额勾稽**：期初 + 进账 − 出账 对不上期末，就把差额写进 `note`，页面上看得见。
实测把一笔 128.00 改成 1128.00，它报「差 1000.00，多半是有笔交易读漏了或
金额读错了」。账单没给期初期末时它也会说一声「这次没做勾稽」——
**不能让「没验」和「验过了」看起来一样。**

体检那边没有对应的自动校验（指标没有勾稽关系），只能靠 `--attach` 留原件回查。

## 网页内的对话（/chat）

AI SDK v7 + `deepseek-v4.1-flash`（走阿里云 DashScope 的 OpenAI 兼容接口）。
底栏第一格从「记录」改成了「对话」—— 对话产生的就是那些记录，纯时间线
收进对话页顶部的「完整记录」。

**动作的边界就是 `src/lib/agent-tools.ts` 那张表**，目前九个：建/查/改待办、
存/查资料、留档、归档文件、读账单入库、读体检报告入库。模型只能做这些，做不了别的 —— 这正是不用通用 coding agent
的理由：它拿到的是一把有限的钥匙，不是一个 shell。

工具**不走 CLI**。`secretary.mjs` 的 commands 依赖模块级的 argv/flags，没法当
函数调；spawn 子进程又要拼参数字符串，模型多写一个空格就拼错。这里直接走
Prisma，参数由 zod 挡在门口，填错类型根本进不来。CLI（`scripts/secretary.mjs`）仍然留着，
给在 Claude Code 之类的编程助手里用的人，两边共用一个数据库。

三个坑，都是实测撞出来的：

- **推理模型要留够 `maxOutputTokens`**。它先思考再产出正文，给小了会把
  token 全花在 reasoning 上，接口返回 200 但 `content` 是空字符串。现在给 32768（做页面要写整段 HTML，4096 不够）。
- **思考过程走单独的流**（`reasoning_content` → `sendReasoning: true`），
  前端折叠显示。不单独渲染的话，要么看不见它在想什么，要么把思考当答案。
- **必须在 system prompt 里写死今天几号**。模型不知道当前日期，而这个秘书
  干的活大半跟日期有关。给了之后实测「下周三」能正确算成 2026-09-23。

跑之前先自检：

```bash
node scripts/check-ai.mjs
```

列出服务器上真正可用的模型（DashScope 的 base_url 和模型 ID 有好几种说法，
文档互相打架，直接问服务器最省事）、发一句话、发一张图。第三步尤其要紧 ——
账单和体检报告两个模块全押在视觉上。

## 在对话里传文件

账单照片、体检报告直接拖进对话（选文件 / 粘贴 / 拖拽），AI 读完入库，
原件跟着挂上去。**这是「自封装」的最后一块** —— 在此之前所有读图入库的活
都只能靠命令行做，普通用户用不上。

三条路径实测跑通：

| 传什么 | AI 做了什么 | 结果 |
| --- | --- | --- |
| 招行 4 月账单图 | 读出 5 笔 → `importBill` | 勾稽通过，原件挂在账单下，`/finance/2026-04` 正常 |
| 同一张图**抹掉一行**再传 | 读出 4 笔 → `importBill` | 工具和模型各自独立算出差 128.00，三条 warning 顶到台面上 |
| 医保缴费 txt | 读到正文 → `saveFile` | 归到「保单」，备注里写清了检索关键词 |

体检报告图也测了：9 项指标全录（含「阴性」「轻度脂肪肝」这类没数字的，
`numValue` 正确留空），4 项异常识别对。

几个决定：

- **工具是工厂不是常量**。`buildAgentTools({ incoming })` —— `execute` 只拿得到
  模型给的参数，拿不到原始附件，得用闭包把这一轮的文件带进去。
- **模型看不了的东西要裁掉，并且说清楚**。图片原样送；txt/csv/json 解成文字送
  （模型看不了 file part 但看得懂文字，一份 CSV 账单这样就能读）；PDF 之类换成
  一句「你看不了它的内容」—— 不说清楚模型会假装读过然后编内容。
  历史轮次的 data URL 一律裁掉，几 MB base64 每轮重塞一遍，几轮就爆上下文。
- **没被任何工具认领的文件挂到那条消息上**，否则就是 uploads/ 里的孤儿：
  磁盘上有、平台上看不见、备份打走了也没人知道是什么。
- **重导覆盖时原件跟着换**（连磁盘字节），但只在这次带了原件时才动旧的 ——
  用户发文字来纠正某一笔时，原件还是上次那份。

## AI 做的页面（/pages）

对话里说「做个页面看看这几个月钱花哪了」「做个贪吃蛇」，AI 写一整段 HTML
存进 `Page` 表，「页面」栏目里点开看、全屏、下载成单个 HTML 文件。
思路来自作者的另一个项目 livepage，**但只搬了「AI 写 HTML、容器来展示」这一半**：

- **没搬 livepage 的通用 `records` 表**。这边的数据已经在定好结构的表里，
  再来一张 JSON 表就是两份数据各自长。所以页面是**快照**：AI 先用只读工具
  （`queryFinance` / `queryHealth` / `queryPolicies`，见 `lib/data-tools.ts`）
  查好数据，连数字一起写进 HTML。过时了点「用最新数据重做」。
- **一律沙箱展示**（`lib/pages.ts`）：响应头 CSP `sandbox allow-scripts` +
  `default-src 'none'`。AI 读过的上传文档、搜索结果里可能夹带指令，被写进页面
  脚本；同源的话它能调所有接口。实测：页面脚本拿不到 cookie、调不了 `/api`、
  发不出外部请求和图片信标。代价是不能用 CDN 图表库 —— 反而让下载下来离线能开。
- **整页 HTML 不进对话历史**（`chat-context.ts` 的 `shrinkToolParts`）：
  否则做三个页面，此后每轮都背着几万 token。存一句占位，要改先 `getPage`。
- 沙箱里原生 alert 被吞、localStorage 抛异常 —— 注入一小段脚本换成提示条和
  内存版。手机没有方向键、游戏结束要能重来，写在 `savePage` 的工具描述里。

**装好就带 8 个示例**（`samples/pages/` → `lib/sample-pages.ts`）：游戏、教育、生活、工作各两个。
绿色版是空库，「页面」空着没人想得到能做什么。几条规矩：

- 只放自带玩法的小程序，不放数据快照 —— 空库没数据可画，编的数据会被当成自己的账。
- **用我们自己的模型真实生成**，只修明显的毛病（单词卡少个 `id` 整页点不动、番茄钟空提示条
  露出半截、房贷页写死了一个核实不了的 LPR 日期）。手写得比模型做得好，用户照着说做不出来，反而失望。
- 详情页上是「在对话里这样说就能做出来：「……」」+「照这个改一个自己的」按钮。
- **删了不回来**：Setting `seeded.samplePages` 记着放过哪些 key，启动时只补没放过的。
  以后加新示例，老用户也补得上新的那几个。用户在对话里改过的，`sample` 清空，算他自己的。
- 改示例：改 `samples/pages/*.html` 或 `manifest.json`，跑 `node scripts/build-samples.mjs`
  编进 `sample-pages.data.ts`（编进模块而不是运行时读目录 —— 桌面端 standalone 产物里不一定有那个目录）。

实测：贪吃蛇 75 秒做完、手机能玩；支出分析页三个月数字跟库里逐月对得上；
「用最新数据重做」原地更新、旧版进历史可恢复。

踩到的坑：**日期要按本地时间算**。交易存的是本地零点（UTC 前一天 16:00），
第一版查询工具用 `toISOString()` 取日期，7/1 的工资掉进了 6 月。

## 多个对话

像 ChatGPT 那样：`/chat` 是新对话，`/chat/<id>` 是某一个，宽屏左边常驻列表
（按今天 / 昨天 / 7 天内 / 30 天内 / 更早分组），窄屏收进页头左上角的抽屉。
第一轮聊完 AI 起个标题，「⋯」里能改名、删除。

**数据层自己做，界面照 Vercel Chatbot 模板和 assistant-ui 的样子**。那两个
都绑着各自的存储和消息格式，这边的消息早就在 `Message` 表里、跟任务附件交织着，
搬过来要改的比自己写的多。

- **`Message.conversationId`**：对话页说的话挂上去；**任务页的留言不挂**，只在任务页看。
- **上下文和压缩摘要按对话分开**（`chat-context.ts` 按 `conversationId` 过滤）。
  资料、任务、页面这些是全局的，哪个对话里都查得到 —— 跨对话记住的东西就靠它们，
  没另做「记忆」。
- **老数据一次性迁移**（`schema-upgrade.ts` 的 `Conversation.legacy`，Setting 里记
  `migrated.conversations`）：原来那一条长时间线整个收进「以前的对话」。
- **新对话的 id 在页面上先生成**，第一句话发出去时服务端 upsert，前端用
  `history.replaceState` 换地址 —— 不重新加载，流着的这一轮不能断。
- **删对话不删挂在任务上的消息**，只摘出来；对话里建的任务、资料、页面都不受影响。
- CLI 的 `log` / `reply` 不带 `--task` 时接在最近的对话后面（`--conversation <id>` 指定）。

实测：两个对话各自的上下文互不相通（A 里说的暗号 B 答不出，回到 A 答得出）；
新对话发完第一句地址变成 `/chat/<id>`、列表先乐观放一条、几秒后换成 AI 起的标题；
刷新、改名、删除、从搜索结果跳到对话里的那一条，都对。

踩到的坑：

- **乐观更新被紧接着的拉取冲掉**。发出第一句就通知列表，列表乐观放一条再去服务端拉，
  可那时服务端多半还没建这个对话。先记着乐观的那几条，拉回来里有了再撒手。
- **不能用 `router.refresh()` 更新列表**：服务端重给一份历史，`<Chat>` 手里
  `useChat` 那一轮还在，页面上就重复了。列表自己用 server action 拉。
- **浏览器后退回到新开过的对话，页面是空的**。地址是 replaceState 换的，Next 按
  路由结构恢复，拿到的是 `/chat` 最近一次渲染（后来点的那个空白新对话）。
  `<Chat>` 发现「我是空白新对话、地址却指着别的对话」就照地址 `router.replace` 一次
  （`refresh` 不行，它拉的是路由器自己记的 `/chat`）。
- sticky 的列表栏被 layout 的 `pb-10` 顶上去半截：网格加 `lg:-mb-10` 抵掉。

## 还没做

**跨对话的记忆**：现在一个对话里说过「我对花生过敏」，换个对话就不知道了，
除非当时存进了资料库。要做的话是一张摘要/事实表，每轮带上 —— 先看用起来缺不缺。

**AI 事后看不了原件**：上传的图片、文档原样存在 `data/uploads/`，页面上点得开，
但 AI 只在上传那一轮看得到（之后历史里换成一句「［上一轮上传的文件：xx］」，
不然几 MB 每轮重塞）。日后它能知道的，只有当时写进库的结构化数据，加上同一个对话里
它当时的回复（会被压缩）。当时没记下的细节 —— 比如账单图上的商户电话 —— 就问不回来了。
要补的话加两个工具：「列出附件」（按对话/任务/时间找）+「重新看附件」（按 id 把原图
或拆好的文字再喂一次）。代价是每次调用重新花一遍读图的 token。
2026-09-24 讨论过，先不做，等真遇到「事后想问原件细节」再说。

**其余模块的工具**：专题、文稿还没接进对话，现在只能从各自的页面看。
（财务、健康、保险已经接了 —— 导入走上面那两个 import 工具，查询走 data-tools。）

**页面读写数据**：现在页面是快照，游戏存不了最高分、番茄钟记不了任务。要做的话
搬 livepage 的数据桥（`postMessage` 请父页面代办、只放行声明过的表），别给沙箱开同源。
