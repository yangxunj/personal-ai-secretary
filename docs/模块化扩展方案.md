# 模块化扩展方案（暂缓，备查）

> 2026-10-02 讨论后**暂不执行**。先试轻量方案：用户有自定义需求时让 AI 在「页面」里现写一个。
> 轻量方案撑不住了（见文末「什么时候该回来做这个」），再按这份执行。

## 想解决什么

侧栏里的功能（任务、资料、财务、健康、专题、文件、页面）都是按「家庭 / 个人秘书」配的。
想扩展更多使用场景，每个场景有配套的数据表和页面，用户在设置里决定侧栏显示哪些。

## 现状的问题

一个功能散在六处，加一个模块要改六个地方：

| 哪里 | 放什么 |
| --- | --- |
| `prisma/schema.prisma` | 数据表 |
| `src/lib/schema-upgrade.ts` | 老用户库的补表 SQL（桌面端没有 prisma CLI） |
| `src/app/(app)/<模块>/` | 页面 |
| `src/lib/agent-tools.ts` / `data-tools.ts` | AI 的写入、查询工具 |
| `src/lib/system-prompt.ts` | 告诉模型什么时候用这些工具 |
| `src/components/nav-tabs.tsx` + `src/lib/i18n/en/` | 导航入口、英文 |

模块越多，系统提示词和工具清单越长：每轮都多花 token，模型也更容易选错工具。

## 方案

### 第一步：侧栏开关 + 模块化改造（基础，先做）

每个模块是一个对象，自带它的全部东西：

```ts
// src/modules/<id>/index.ts
export const insurance: Module = {
  id: 'insurance',
  nav: { href: '/insurance', label: '保险', icon: 'shield' },
  tools: (ctx) => ({ queryPolicies, … }),          // 关掉时不注册
  prompt: '保单：用户说「保单什么时候交钱」→ queryPolicies …', // 关掉时不拼进系统提示词
  defaultEnabled: true,
};
```

- 开关存 `Setting` 表，key `modules.enabled`，JSON 数组。
- **关掉一个模块 = 导航隐藏 + AI 工具不注册 + 提示词片段不拼**。三样一起，否则 AI 会往用户看不见的地方存东西。
- 数据表**始终存在**，只是不用 —— Prisma schema 没法按开关增减，也没必要。关了再开，数据还在。
- 「对话」「设置」「搜索」不可关。
- 底栏七格的问题：开的模块超过 7 个时，底栏只放前 6 个 + 「更多」。

### 第二步：挑一个新模块做完整

候选（都符合「拍照或说一句 → AI 读懂 → 结构化入库 → 手机上翻」这个本产品最强的路数）：

| 场景 | 表 | 亮点 |
| --- | --- | --- |
| **孩子学习 / 错题本** | `Mistake`（原图、题目、正确答案、知识点、年级、状态）+ `PracticeResult` | 按知识点归类，生成练习游戏，看哪些总错 |
| **物品与保修** | `Item`（名称、购买日期、价格、保修到期、发票附件） | 到期提醒，坏了一查就知道在不在保 |
| **车辆** | `Vehicle` + `VehicleEvent`（保养、年检、违章、加油） | 跟保险、任务串起来 |
| **旅行** | `Trip` + `TripSegment`（航班、酒店、活动） | 确认邮件 / 截图 → 行程，证件有效期顺便查 |
| **宠物** | `Pet` + 复用健康的结构 | 疫苗、驱虫、体检提醒 |

当时倾向于先做**错题本**：跟「错题做成游戏」直接接上。

### 第三步（最后再说）：用户自定义「集合」

用户说「帮我建个读书记录，要书名、作者、读完日期、评分」，AI 建一个通用集合 + 自动的列表页。
场景无限，但只能是通用表格 / 卡片，做不了专门的图表和提醒。
**等专门模块做了两三个、看清哪些值得专门做，再决定要不要这一层。**

## 工作量估计

- 第一步：中等。现有七个模块都要搬一遍，系统提示词要拆成片段。
- 第二步：每个模块大约相当于当初做「保险」的量（表 + 页面 + 工具 + 提示词 + 英文 + 升级 SQL）。

## 什么时候该回来做这个

轻量方案（AI 现写页面 + 页面自带存储）出现下面的情况，就说明该升级了：

- 同一类页面被反复做、反复改，用户每次都要重新描述一遍 —— 说明这是个稳定的场景，值得固定下来
- 页面里的数据需要**跨页面**用（比如错题既要进练习游戏、又要进学习报告、又要让 AI 按知识点统计）
- 需要提醒、到期、跟任务联动 —— 页面是被动打开的，做不了主动提醒
- 用户开始问「我上个月那个页面里记了什么」，而 AI 查不到
