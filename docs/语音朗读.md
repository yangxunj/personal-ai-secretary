# 回答朗读

主聊天和任务聊天里的 AI 回答下方有「朗读回答」按钮，包括历史回答和本轮完成的回答。默认手动播放：打开聊天、刷新或等待回复时都不会自动合成或播放。

## 使用

- 点击「朗读回答」，开始合成并播放；支持暂停、继续、停止。浏览器阻止异步播放时会显示「播放朗读」，点击即可播放已合成音频。
- 长回答按句子分段，每段最多 500 个 UTF-16 字符（低于服务商 600 字符限制），顺序合成和播放，保留完整正文。只在上一段播完后请求下一段，停止后不再请求后续内容。分段间可能有短暂停顿。
- Markdown 先解析为正文：保留标题、列表、表格内容和链接标题，跳过代码块、删除线、图片、HTML 标签和直接链接地址。思考过程与工具参数不进入朗读。
- 同时只能播放一条回答。开始另一条朗读、开始录音、发送新消息、关闭任务聊天、切换页面或转到后台都会停止对应的朗读及未完成请求。
- 最近一次回答的音频只在内存中短暂缓存，最多 12MB。重复朗读已缓存的片段不重复合成；超过缓存上限的片段会在重播时重新合成。离开聊天释放音频和浏览器对象 URL。

## 配置

在「设置 → 回答朗读」填写密钥、原生 DashScope API 地址、模型和音色，保存后立即生效，密钥留空保留原值。配置与 ASR、聊天模型独立，即使使用本机 Codex 也可朗读。

服务端环境变量作为默认值：

```dotenv
TTS_API_KEY=""
TTS_BASE_URL="https://dashscope.aliyuncs.com/api/v1"
TTS_MODEL="qwen3-tts-flash"
TTS_VOICE="Cherry"
```

新加坡区域使用 `https://dashscope-intl.aliyuncs.com/api/v1`，密钥必须与区域一致。这里使用原生 `/api/v1` 地址，不是聊天模型使用的 `/compatible-mode/v1`。该接入针对 Qwen-TTS 非实时接口，更换为其他模型系列前应核对其接口和音色协议。

桌面版可在设置页配置，或在已有本机 `config.json` 中设置同名 `TTS_*` 字段。不要将个人密钥放进安装包或 Git。

## 数据与接口

`POST /api/tts` 受现有登录和来源检查保护，限制实际请求体、单段文字长度与并行数。服务端先调用阿里云生成音频，再从受限的阿里云结果域通过 HTTPS 下载音频。不向下载域传 API Key，不向浏览器返回带签名的临时地址。音频响应为 `audio/wav`，设置 `Cache-Control: no-store`。

点击朗读会将该段回答正文发送给阿里云，不发送其他聊天历史、思考过程或工具参数。应用不将生成音频落盘或存进数据库；服务商的数据处理以其约定为准。自动化验证只使用虚构测试文字和隔离数据库。

浏览器通过 Blob 音频播放，不额外申请麦克风权限。真实 iPhone/Safari、耳机和扬声器效果需在目标设备验收。
