# 语音输入

主对话和任务对话共用语音输入：点击麦克风 → 录音（最多 60 秒）→ 完成 → 识别文字回填草稿 → 编辑后发送。不会自动调用 Agent 或修改业务数据。

录音时可取消；收起任务聊天、切换页面或离开浏览器会停止麦克风并取消识别。识别失败时可重试，已有文字和附件保留。重试用的音频只暂存在浏览器内存，取消、重新录音或离开页面后释放。

## 配置

在「设置 → 语音输入」填写阿里云百炼密钥、接口地址和模型，保存后立即生效。密钥留空表示保留现有值。设置优先于服务端环境变量，与聊天模型和 Codex 后端独立。

也可以在服务端 `.env` 中配置：

```dotenv
ASR_API_KEY=""
ASR_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
ASR_MODEL="qwen3-asr-flash"
```

北京区域默认地址如上；新加坡区域可使用 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。也可按官方文档使用业务空间专属域名。密钥必须与服务区域匹配，修改环境变量需要重启服务。

桌面版优先在设置页配置；批量预置可在本机 `config.json` 中使用相同的 `ASR_*` 字段。不将开发者密钥打进安装包或提交到 Git。

## 录音与隐私

- 网页必须处于 HTTPS 或本机 localhost / 127.0.0.1 安全上下文。普通 HTTP 局域网地址无法录音；桌面版手机访问的 HTTP 网关同样受此限制。
- 支持具备 MediaRecorder、Web Audio 和麦克风权限的现代浏览器。Chrome/Edge 与 Safari 的原始录音格式不同，由浏览器解码并统一为 16kHz、单声道、16-bit PCM WAV，无需安装 FFmpeg。
- `/api/asr` 沿用登录保护并检查来源、实际请求大小、WAV 结构和音频长度，超时可取消。单实例同一时间只允许一个识别请求。
- 后端将录音以 Base64 发送给阿里云 `qwen3-asr-flash`，不上传公网存储，不在本应用数据库、文件或日志保存原始音频。阿里云的数据处理规则以服务商约定为准。
- 识别文字回填后可修改，只有点击发送才进入普通聊天和 Agent 流程。日期、人名、金额和药名应在发送前核对。

## 验证

自动检查覆盖 WAV 编解码边界、服务端请求格式、取消和错误映射；浏览器验收覆盖录音、取消、重试、草稿保留、60 秒停止、关闭任务窗口和窄屏布局。真实麦克风质量和 iPhone Safari 权限提示仍应在实际设备上验收。

2026-10-15 验证记录：生产构建、英文文案检查、14 项 ASR/现有任务与 Codex 测试通过。隔离 Edge 使用 Windows 合成语音作虚拟麦克风，经浏览器录音、后端和真实阿里云接口完成转写；确认草稿保留、无自动发送、拒绝权限、延迟授权取消、后台切换、失败重试、识别取消、任务窗口收起以及手机布局。60 秒边界由服务端音频样本检查，并在浏览器触发实际截止回调验证资源释放。测试数据库中未产生聊天消息。
