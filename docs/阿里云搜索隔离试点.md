# 阿里云联网搜索隔离试点

2026-10-28。目标：确认只使用现有阿里云百炼 Key 能否为 Pi 提供搜索，避免要求百炼用户再提供 DeepSeek Key。本轮只做官方资料核查和隔离 API 试点，未改生产设置、主 Pi 会话、业务数据库或现有搜索路由。

## 结论

可行。百炼同时提供模型内置搜索与独立 WebSearch MCP。当前 Key 已验证可调用 Responses 的 `web_search` 和 `web_extractor`；独立 MCP 初始化返回 404，未验证成功，不能据此宣称它不存在，也不能仅据此断定是账号未开通。

建议后续为平台 `webSearch` 工具增加百炼适配器：Pi 主对话继续使用当前模型和 session；工具内部用同一百炼 Key 发起独立 Responses 请求，搜索侧可选择已实测的 `qwen3.8-flash`。不要求把整个 Pi 主对话切换到 Responses，也不要求额外搜索 Key。Qwen Code 官方当前实现也采用独立辅助模型配合 Responses 内置搜索的方式。

注意：这条路径是“辅助模型调用服务端搜索后给出摘要”，不等同于 DeepSeek 独立 Search/Fetch API 的原始结构。返回给主 Pi 的结果必须区分搜索摘要、网页读取摘要和可核验来源；不得把辅助模型的概括当成完整网页原文。

## 官方依据

- [联网搜索](https://help.aliyun.com/zh/model-studio/web-search)：Chat Completions 使用 `enable_search`；Responses 通过 `tools` 启用 `web_search`。支持范围按模型和地域区分。`usage.x_tools` 的 count 可在意图阶段置位，不能单独作为实际完成检索或计费的证据。
- [创建响应](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-responses)：Responses 支持内置搜索、网页抽取；网页抽取需要同时注册 `web_search`。未列出的兼容参数可能被忽略，不能将 OpenAI 的同名参数视作已支持。
- [MCP 外部调用](https://help.aliyun.com/zh/model-studio/mcp-external-calls)：WebSearch MCP 可通过 Streamable HTTP 和百炼通用 Key 调用；账号是否需开通、升级或有额度要另行核验。
- [Qwen Code 搜索工具](https://github.com/QwenLM/qwen-code/blob/main/docs/developers/tools/web-search.md)：独立辅助模型通过 DashScope Responses 执行搜索和网页抽取，复用可用的百炼凭据。

## 当前 Key 实测

配置只读取模型相关字段；实际主模型为 `deepseek-v4.1-flash`，北京 DashScope。只提交公开的“百炼联网搜索官方文档”问题。原始 Key、请求头、会话 ID 和服务商原始错误响应不写入日志；诊断错误文本仅保留去密钥后的短消息。回执在 Git 忽略的 `data/dashscope-search-pilot/`。

| 路径 | 结果 | 解释 |
| --- | --- | --- |
| 当前模型 Chat Completions + `enable_search` | HTTP 200，5.493 秒；`usage.x_tools.search.count=1` | 有触发记录，但未返回结构化来源，回答也未包含 URL，不能单凭 count 当成完整检索验收 |
| 当前模型原生 text-generation 端点 | HTTP 400 / InvalidParameter | 本次参数组合未通过，不作为可用方案 |
| 独立 WebSearch MCP 初始化 | HTTP 404 | 官方有该服务，当前调用未跑通；未自动开通或修改账号服务 |
| 当前模型首次 Responses 搜索 | 4 次已完成 `web_search_call` 且有来源，但最终 `incomplete` | 真实搜索执行成功；最终回答未完整完成，不能当成整轮成功；本次返回 32,057 total tokens |
| `qwen3.8-flash` Responses 搜索 | `completed`，4.791 秒，1 次已完成搜索及来源 URL；1,553 total tokens | 已跑通独立搜索请求 |
| `qwen3.8-flash` Responses 网页抽取 | `completed`，25.559 秒，1 次已完成 `web_extractor_call`；2,606 total tokens | 已跑通指定公开网页的读取调用；此回执未保存原文和完整回答，未据此验证逐字内容正确性 |

网页抽取调试中先后遇到参数拒绝：仅注册 `web_extractor` 不符合当前文档；同时注册搜索与抽取后，非思考模式仍报 `Normal mode does not support web_extractor`。改用 `reasoning.effort=low` 后成功。只做搜索时 `reasoning.effort=none` 已通过。

成功搜索回执：`2026-10-28T06-21-40-634Z/receipt.json`；成功抽取回执：`2026-10-28T06-23-44-532Z/receipt.json`。其余回执保留试错过程，不删除失败记录。本次 9 个 HTTP 请求包含失败和初始化；有 usage 的回复合计 41,621 total tokens，以服务商账单为准，不能用该数值推算 MCP 或工具账单。

## 复验与后续边界

```powershell
node scripts/dashscope-search-pilot.mjs --live
node scripts/dashscope-search-pilot.mjs --live --mode=responses --model=qwen3.8-flash
node scripts/dashscope-search-pilot.mjs --live --mode=extract --model=qwen3.8-flash
```

脚本不自动重试，每次最多 10 个 HTTP 请求，每个请求 55 秒超时；内置搜索在服务端的执行次数不等于 HTTP 请求数。提示词要求只执行一次不构成服务端强制次数上限。之前探测曾传入 `max_tool_calls`，但当前官方文档未列出，后续脚本已移除，不能假定它生效。

尚未把适配器接入 Pi，也未验证平台流式 UI、平台来源引用、搜索侧取消/预算、跨地域 Key、全部模型、独立 MCP 开通或安装包。后续接入应保留现有搜索开关、最小公开查询、超时/预算、来源校验，并对费用和可能的网页抽取延迟作清晰说明。此次不更改 Codex 搜索。
