# 香港周末活动专题（安卓试点）

在安卓应用底栏进入「专题」→「周末去哪」，可填写出行偏好，然后点击「查询并 AI 推荐」。应用读取香港旅游发展局、香港公共图书馆和康文署博物馆的公开资料，再让 DeepSeek 归纳活动摘要并推荐最多 5 项；可展开全部活动，查看场次和来源链接。活动的费用、报名要求、适龄、开放时间及临时变化请以主办方页面为准。

推荐使用设置中已配置的 DeepSeek 密钥，会把活动摘要和填写的偏好发送给服务商。活动较多时分批比较，可能发起多次模型请求并产生 API 费用；偏好输入框本身不跨重启保存。每个活动组会发送精简摘要和最多 8 个场次，不代表 AI 逐字阅读了所有原网页。没有设置密钥时仍可查询和查看活动，但不能生成 AI 推荐。

查询日期按香港时间计算；周日查询时仍覆盖当天所在周末。图书馆按月检索，跨月周末查询两个月。结果按有固定时间、即将结束、适合家庭及其他活动分组；主题书架排除在活动清单之外。其他活动超过 50 项时会显示省略数量。

结果和有效推荐保存在当前安卓设备上。页面显示活动日期和更新时刻，过期结果会提示重新更新。来源失败会标明结果不完整，AI 仅根据成功获取的来源推荐；全部失败时保留上次结果。首次查询需要联网，可能耗时。官网改版、网络或网站限制可能导致某些来源暂时不可用，可点击页面中的来源链接核查。

本试点只接入「周末去哪」专题和手动查询入口；个人秘书平台的其他专题、附件、自动定时任务与跨设备同步尚未接入，安卓对话也暂不能调用此专题。原个人平台的数据不会自动迁入。地点远近和家庭偏好暂未同步，未填写的住址、年龄或交通偏好不会作为已知信息提供给 AI。

## 开发与迁移说明

日期处理、来源解析、去重、分组与推荐规则位于 `src/lib/weekend/`；安卓通过 `WeekendClient` 提供限定来源的只读联网适配，模型连接复用现有原生 DeepSeek 通道，数据渲染使用文本节点。推荐只接受能对应现有活动的 ID；事实仍从原始活动记录取。专题卡片与网页共用 `TopicCardContent`。`scripts/weekend-engine.test.mjs` 和 `scripts/weekend-recommend.test.mjs` 用合成数据验证来源失败、分批和推荐结果校验。

信息源：

- [香港公共图书馆活动](https://www.hkpl.gov.hk/tc/extension-activities/all-events/this-week)

这是基于个人项目原有活动查询流程提取的通用实现，没有携带个人家庭住址、私有专题编号或密钥。后续修改共用规则应同时验证网页、Windows 和安卓的实际接入情况，不能仅凭共用文件声称三端功能已经同步。
