# 香港周末活动专题（安卓试点）

在安卓应用底栏进入「专题」→「周末去哪」，点击「更新本周末活动」。应用会读取香港旅游发展局、香港公共图书馆和康文署博物馆的公开资料，在手机本地筛选并显示；展开活动可查看场次和来源链接。活动的费用、报名要求、开放时间及临时变化请以主办方页面为准。

查询日期按香港时间计算；周日查询时仍覆盖当天所在周末。图书馆按月检索，跨月周末查询两个月。结果按有固定时间、即将结束、适合家庭及其他活动分组；主题书架排除在活动清单之外。其他活动超过 50 项时会显示省略数量。

结果保存在当前安卓设备上。页面显示活动日期和更新时刻，过期结果会提示重新更新。来源失败会标明结果不完整；全部失败时保留上次结果。首次查询需要联网，可能耗时。官网改版、网络或网站限制可能导致某些来源暂时不可用，可点击页面中的来源链接核查。

本试点只接入「周末去哪」专题和手动更新入口；个人秘书平台的其他专题、附件、自动定时任务与跨设备同步尚未接入，安卓对话也暂不能调用此专题。原个人平台的数据不会自动迁入。地点远近和家庭偏好暂未同步，应用不会根据未经核实的地点猜测距离。

## 开发与迁移说明

日期处理、三个来源的解析、去重与分组位于 `src/lib/weekend/`；安卓通过 `WeekendClient` 提供限定来源的只读联网适配，数据渲染使用文本节点。专题卡片与网页共用 `TopicCardContent`。`scripts/weekend-engine.test.mjs` 使用合成数据验证日期、来源失败与分组规则。

信息源：

- [香港旅游发展局活动](https://www.discoverhongkong.com/tc/events.html)
- [香港公共图书馆活动](https://www.hkpl.gov.hk/tc/extension-activities/all-events/this-week)
- [康文署博物馆展览](https://www.museums.gov.hk/tc/web/portal/what-s-on.html)

这是基于个人项目原有活动查询流程提取的通用实现，没有携带个人家庭住址、私有专题编号或密钥。后续修改共用规则应同时验证网页、Windows 和安卓的实际接入情况，不能仅凭共用文件声称三端功能已经同步。
