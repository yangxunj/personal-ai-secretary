# 知识幻灯片与秘书界面 DSH 试验

这是个人 AI 秘书的隔离试验插件，不连接或修改秘书应用的数据库。幻灯片以 Markdown 保存在 DSH 本机数据目录；AI 可创建、列出和读取作品。插件更新保留原有数据目录，不要为更新而清理或重置 DSH 数据。

## 电脑体验（0.3.0）

在 DSH 桌面版的插件管理页面使用本地文件安装 `dsh-secretary-slides-pilot-0.3.0.tgz`；如提示重启，完全退出后重新打开 DSH。安装依赖可能需要联网。

侧边栏的“知识幻灯片”可以查看作品；新增“秘书界面试验”入口，在 DSH 主区域展示秘书平台的导航和知识幻灯片。它直接复用秘书平台的导航组件和 Marp 幻灯片阅读器。试验保留 DSH 自身侧边栏，因此目前会出现两层侧边栏；点击试验导航里的“对话”返回 DSH 对话。其他栏目尚未接入，暂不可点击。

试验步骤：打开“秘书界面试验”，检查已有作品，打开一份多页作品并翻页、返回列表，再点击“对话”；也可在原“知识幻灯片”入口查看相同作品。通过对话让 AI 创建作品后，在列表点击刷新。当前不支持从页面编辑、删除、导出 PPTX 或跨设备同步。

该版本针对 DSH `0.2.2-rc.2` 的桌面运行时构建；独立测试环境验证不等于用户桌面应用验收。暂未验证 DSH Go 的新界面，请以电脑试验为准。

## 开发

在仓库根目录运行 `node experiments/dsh-slides/build-shared.mjs` 更新共享数据校验代码，运行 `node experiments/dsh-slides/build-client.mjs` 编译共享 UI 组件及其许可说明。安装依赖后运行 `node --test experiments/dsh-slides/test/plugin.test.js`。客户端使用 DSH 宿主提供的 React。插件源码继承仓库的 AGPL-3.0-or-later 许可。
