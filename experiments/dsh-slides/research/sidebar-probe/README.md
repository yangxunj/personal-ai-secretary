# DSH 侧边栏替换探针（仅隔离研究）

这个目录记录失败边界，不是可交付插件。不要安装到日常使用的 DSH，也不要在有真实数据的配置中运行。`0.0.4` 会使自定义侧栏抛错，DSH 回退到默认侧栏；不能据此认为替换已经完成。

## 已验证的现象

使用 DSH 桌面版 0.2.2-rc.2 自带运行时，分别在全新隔离 DSH_HOME 的 Web 实例中安装探针并观察实际界面：

1. 禁用 `ui-sidebar`，由探针声明其子插槽并占据 `sidebar`：自定义单列侧栏、原生对话、插件页面和账号入口能出现；但工作区和会话列表没有出现。至少工作区组件的客户端清单依赖原 `dsh-client-ui-sidebar`，因此不能通过简单禁用原组件保证其他功能正常。
2. 保留 `ui-sidebar`，探针也声明同名子插槽：启动失败，提示 `sidebar.panellist` 已声明。子插槽不能同时由两个侧栏声明。
3. 保留 `ui-sidebar`，探针不声明子插槽且与其使用相同优先级：启动失败，提示 `sidebar` 同优先级已注册，并提示使用不同优先级（数字越小越优先）。
4. 本目录版本使用 `priority: -1` 且不声明子插槽：可以启动，但探针不能获得 `renderSlot`，调用时报 `renderSlot is not a function`，DSH 将失败侧栏回退为原侧栏。原生会话列表仍在，说明回退生效；不是替换成功。

这些结果只说明所试方法和当前版本的行为，不排除其他受支持的扩展方式。没有在真实桌面窗口或用户数据上试验，也没有验证实际模型对话、移动端、升级兼容或无障碍行为。

## 复现

使用独立的临时 DSH_HOME 和 AGENTS_HOME，先确认没有指向用户数据目录，再将此目录 `npm pack` 后安装到该隔离配置并启动 DSH Web。浏览器控制台可观察侧栏报错和回退。探针不得作为常规插件分发。

## 后续方向

继续研究如何在维持会话、设置和动态插件入口依赖的同时替换整个侧栏，例如独立构建或替换 DSH 的侧栏组件；需要先确认依赖、许可证、升级和回退机制，做隔离原型并完整验证，再决定是否提供安装包。不要以隐藏或模拟界面的方式宣称已经完成统一。

## 2026-11-13：组件包替换原型

`build-isolated.mjs` 只读取本机 DSH 桌面 0.2.2-rc.2 的 `app.asar`，校验原始侧栏组件的 SHA-256，然后在忽略的 artifacts 目录生成一个侧栏包；它将项目的 `SideNavView` 编入副本，同时保留原有工作区、设置与插件插槽，不修改安装目录。使用其他版本或文件不匹配时构建直接失败。示例：

```powershell
node experiments/dsh-slides/research/sidebar-probe/build-isolated.mjs 'C:\Users\yangxunj\AppData\Local\Programs\DeepSeek Harness\resources\app.asar'
```

在全新隔离 DSH_HOME 的 Web 配置中，以本地侧栏组件包替换默认侧栏并安装幻灯片插件：共享秘书导航、原生工作区与设置显示在同一侧栏；设置打开、侧栏收起恢复、幻灯片列表、翻页及返回对话均通过浏览器检查。其他秘书栏目尚未接入，原有 DSH 插件入口与秘书导航仍存在重复，界面不是最终设计。

旧版 0.3.0 幻灯片插件在隔离环境会导致新会话初始化报告重复 persona；在相同条件下去掉那组 DSH 内部包的轻依赖探针可初始化新会话。具体根因和真实模型对话尚未验证。没有在用户的桌面应用里安装或验证该侧栏包。

这是版本锁定的私有实现试验，改写的是 DSH 编译产物，不是稳定的公开插件扩展点；构建脚本仅用于可复现研究，不是安装程序。原组件为 MIT 许可，生成目录保留原 LICENSE；如未来分发衍生包，需继续核对许可证、完整来源、升级和回退流程。DSH 升级会触发哈希保护，不能自动假定兼容。

## 2026-11-13：独立体验流程

新增 `isolated-pilot.ps1`，固定专用 DSH_HOME、AGENTS_HOME 和默认工作区，以便安装、启动、恢复默认侧栏及重新启用；文件锁避免脚本管理的试验运行时并行修改。恢复时除移除依赖记录，还检查并删除指向试验包的专用目录联接；对意外目标拒绝操作，不删除联接目标。安装和试验侧栏启动均核验 DSH 组件版本与哈希，未知版本拒绝运行。

实际隔离 Web 实例中，复用导航已去除展开状态下的重复入口，并将对话和幻灯片放在首位，顺序也体现在键盘及无障碍导航中；原生会话、设置和插件入口保留。真实模型在专用工作区调用幻灯片工具创建测试作品，作品在页面中可见。停止后执行恢复，再启动检查，默认侧栏、试验会话及作品均可访问；重新启用也已完成。安卓共享网页构建及 TypeScript 检查通过。未验证真实桌面窗口内替换或其他 DSH 版本。

此机体验方法、隔离范围和恢复步骤见 [体验说明](./体验说明.md)。其中工作区是默认值，用户仍可自行选择其他目录；脚本仅管理其启动的试验进程，不能锁住绕过脚本手工启动的 DSH。

## 2026-11-13：独立桌面窗口

在同版本 DSH 桌面程序中验证了独立 profile 与 Electron `--user-data-dir`；独立 Electron 探针确认 `userData` 和 `sessionData` 指向参数指定的目录。桌面 DSH 有单实例锁，启动脚本要求其他 DSH 桌面实例先完全退出，不结束其他进程。该脚本使用独立数据、Electron 目录、默认工作区及单独构建的侧栏包，保留原有桌面安装。

实际桌面窗口中已验证单侧栏、幻灯片列表与翻页、窗口侧栏收起展开和设置入口。关闭隔离实例后，执行恢复并重启，确认 DSH 原侧栏及测试作品存在；重新启用试验也已完成。启动脚本持有文件锁，运行中拒绝恢复或重装，版本不匹配时拒绝启动。试验尚未配置模型，桌面窗口内真实模型调用及用户体验待验收。用户可从试验应用内自行登录或配置模型，不应复制或索取现有密钥。

双击入口和操作说明见 [桌面体验说明](./桌面体验说明.md)。桌面试验和 Web 试验各有独立数据与侧栏构建目录，日常 DSH 不自动与其同步。脚本无法阻止用户绕开脚本自行启动其他进程，使用时应遵循完全退出要求。
