# DSH 单侧栏隔离试验

这是在本机 DSH 0.2.2-rc.2 运行时上启动的**独立 Web 试验**，在浏览器里显示，不替换日常 DSH 桌面软件的界面。此电脑上已完成安装；其他环境需要项目依赖、Node.js、npm，以及相同版本的 DSH 桌面运行时。

## 开始体验

1. 双击本目录的 `启动单侧栏试验.cmd`。保持打开的命令窗口，稍后浏览器会打开试验页面。
2. 左侧的“对话”和“知识幻灯片”可以切换；其余秘书栏目灰色显示，尚未接入。DSH 的插件、自动化任务、会话列表与设置入口保留。
3. 可以打开已有的“隔离工作区验证”测试作品并翻页，或者在试验对话中让 AI 新建一份幻灯片，再到知识幻灯片页面刷新查看。
4. 结束时关闭命令窗口，试验服务随之停止。

试验使用 `experiments/android-shared/artifacts/dsh-single-sidebar-v2-home` 中的独立 DSH 数据、设置和工作区，不自动读取或同步日常 DSH 的作品、会话或配置。模型设置也可能需要在试验内单独配置；不要把密钥写入项目文件。可在 DSH 里主动选择其他工作区，届时访问范围以实际选择为准。

## 安装、恢复和重新启用

一般体验无需手动安装。本仓库根目录 PowerShell 中可执行：

```powershell
# 停止试验服务后，安装或重新启用单侧栏试验
powershell -NoProfile -ExecutionPolicy Bypass -File experiments/dsh-slides/research/sidebar-probe/isolated-pilot.ps1 -Action Install

# 恢复独立试验配置中的 DSH 默认侧栏，保留其中的会话和作品
powershell -NoProfile -ExecutionPolicy Bypass -File experiments/dsh-slides/research/sidebar-probe/isolated-pilot.ps1 -Action Restore
```

命令只操作上面列出的专用试验配置。试验运行中安装和恢复会被拒绝，应先关闭命令窗口。恢复后再次执行 `Install` 可重新启用；不会清理已有试验会话与作品。

## 当前限制

侧栏实现基于指定版本 DSH 的组件副本，并非 DSH 稳定的官方插件接口。安装和试验侧栏启动前都会核对版本及侧栏文件哈希，不匹配时停止；不要通过修改校验绕过。其他栏目暂不可用。独立浏览器试验已通过，真实桌面窗口集成、跨设备同步和其他 DSH 版本尚未验证。
