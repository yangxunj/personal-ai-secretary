# DSH 桌面单侧栏隔离试验

这是运行在真实 Windows DSH 桌面窗口中的独立试验，当前只针对本机 DSH `0.2.2-rc.2`。它使用单独的 DSH 数据、Electron 用户目录、模型配置和默认工作区，不自动复制或同步日常 DSH 的会话、作品或设置；日常应用和数据未被替换。

## 开始体验

1. 完全退出日常 DSH，包括系统托盘中的后台程序。桌面应用有单实例锁；试验脚本检测到桌面程序仍在运行时会拒绝启动。
2. 双击本目录的 `启动桌面单侧栏试验.cmd`。试验启动后请保持命令窗口打开。
3. 首次启动可能显示登录或 API Key 设置，模型需要在**试验应用内**单独配置。不要把密钥发给开发者或写入项目文件。
4. 左侧“对话”和“知识幻灯片”可切换；打开已有的“桌面侧栏验证”测试幻灯片并翻页。配置好模型后，也可以让 AI 新建作品，在幻灯片页面刷新查看。
5. 检查侧栏收起和展开、会话列表、插件入口及设置；灰色秘书栏目尚未接入。
6. 结束时从应用菜单或 Windows 系统托盘选择**退出 DeepSeek Harness**，等待命令窗口结束。仅关闭窗口可能让程序留在托盘；试验完全退出后才能运行日常 DSH 或执行恢复。

若用户主动在试验中选择其他工作区，DSH 可以访问所选目录；默认工作区位于试验数据目录中。

## 安装和恢复

此电脑已安装试验，无需重复安装。以下命令只操作专用桌面试验配置，运行前需要完全退出所有 DSH 桌面进程：

```powershell
# 在仓库根目录 PowerShell 中重新启用或安装试验侧栏
powershell -NoProfile -ExecutionPolicy Bypass -File experiments/dsh-slides/research/sidebar-probe/desktop-pilot.ps1 -Action Install

# 恢复独立桌面试验中的 DSH 默认侧栏，保留试验会话和作品
powershell -NoProfile -ExecutionPolicy Bypass -File experiments/dsh-slides/research/sidebar-probe/desktop-pilot.ps1 -Action Restore
```

安装和启动会校验所安装 DSH 的侧栏版本和文件哈希；版本不符会停止。独立配置的数据位于 `experiments/android-shared/artifacts/dsh-desktop-isolated-home`，Electron 个人设置位于相邻的 `dsh-desktop-isolated-electron` 目录，不会随 Git 备份。脚本不会清理这些目录。

## 已验证和待验证

已在独立桌面窗口验证侧栏、幻灯片列表与翻页、侧栏收起展开、设置入口，以及恢复后默认侧栏和测试作品。窗口中的真实模型对话需要用户在独立配置中完成模型设置后再验收。其他 DSH 版本、桌面自动更新后的兼容性、跨设备同步尚未验证。
