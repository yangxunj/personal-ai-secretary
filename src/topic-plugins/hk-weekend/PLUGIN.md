# 周末去哪：专题插件

- 标识：`hk-weekend`；入口：`/topics/weekend`。
- 用途：查询香港官方周末活动，按活动摘要生成家庭出行推荐。
- 所需平台能力：限定来源的只读联网、本机缓存、外部 HTTPS 链接、模型可用性与模型请求。
- 数据：活动和推荐缓存在安卓既有 `weekend-cache` 中；可选出行偏好只用于用户主动发起的模型请求。活动摘要和填写的偏好会发送给模型服务商，可能产生费用。
- 运行限制：原始来源可能失效或受限；缺失来源需明确提示，活动详情以官方页面为准。不能从此插件推断用户住址、年龄或距离。
- 文件：`index.mjs` 为元数据和页面入口，`panel.mjs` 为界面，`engine.mjs`、`service.mjs`、`recommend.mjs` 为可复用规则；`android-adapter.mjs` 和 `android/` 是安卓适配，`styles.css` 是页面样式。

这是随应用构建的受审插件，不支持下载或执行外部插件。能力声明供主程序校验接口，并不构成独立进程或安全沙箱。
